# Google Ads Search: таргетинг по языку для испанских ключей (Landver, 2026-11-11)

**Не проверено на нашем кабинете.** Источники — поиск 11.11.2026 (официальная справка и отраслевая пресса), страницы целиком не читались, только выдержки поиска.

- Официальная справка «About language targeting» (`support.google.com/google-ads/answer/1722078`): в Search можно выбрать один, несколько или все языки; объявления подходят по запросам, где ключ совпал и Google считает, что пользователь понимает хотя бы один из выбранных языков. Пример справки — человек, понимающий английский и испанский.
- Старый блог Google (2011): таргетинг по языку шёл по языку интерфейса пользователя, поэтому при выборе только одного языка билингвы с другим интерфейсом выпадают. Практика: для испанских ключей в США выбирают оба языка (Spanish + English).
- Новое (справка и пресса, 2026): с сентября 2026 кампанийная настройка языка у Search-кампаний убирается, язык определяется языком объявлений. На 11.11 проверка `validate_only` на нашем аккаунте приняла языковые критерии Spanish и English — отказ при записи не исключён.
- Расхождение источников: справка описывает модель «пользователь понимает язык», блог 2011 — «язык интерфейса»; какие сигналы реально использует Google сегодня, официального списка не нашли.
- Решение для Landver: Spanish + English у испанской кампании (допущение), флаг `--no-language` в `Скрипты/gads_landver_spanish_build.py`, если запись откажет. См. `Клиенты/Andverpersonalinjury/Креативы/spanish_campaign_plan_2026-11-11.md`.
