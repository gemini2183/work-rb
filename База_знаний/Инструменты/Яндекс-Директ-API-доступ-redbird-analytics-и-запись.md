# Директ API: доступ redbird.analytics и управление кампаниями

## Проверено 2026-10-26 (только чтение, по токену из `google-cloud-jobs/REFERENCE.md`)

- Токен рабочий, это боевой доступ (не песочница): суточный лимит баллов 120 000 на кабинет Груминг - Северная 3; у других клиентов свои лимиты (168 000 – 1 947 500), лимит зависит от кабинета клиента.
- Сервис `agencyclients` отвечает **54 «Нет прав для доступа в агентский сервис»**: redbird.analytics не является агентством в смысле Директа, это **представитель** в кабинетах клиентов. Списка клиентов по токену не получить, каждый кабинет подключается отдельно через `Client-Login`.
- В 13 активных кабинетах листа «Директ» права `EDIT_CAMPAIGNS`, `IMPORT_XLS`, `TRANSFER_MONEY` = YES. Но токен redbird.analytics стоит только у 2 активных (Груминг - Северная 3, Транзит); у остальных 11 в листе токены самих клиентов, это права владельца, не наши.

## Запись проверена 2026-10-26 (`campaigns.add`)

Кабинет Груминг - Северная 3 (login `porg-w3seuhbn`), токен redbird.analytics: создана кампания 715470053 «Тестовая кампания для тестирования API» (TEXT_CAMPAIGN, DRAFT/OFF, стратегия «максимум кликов» с недельным лимитом 300 ₽ на поиске, сети выключены). Читается обратно, 5 рабочих кампаний кабинета не затронуты. Скрипт: `Скрипты/direct_campaign_create.py` (по умолчанию план, запись с `--execute`). Кампания пустая и показываться не может; удалить можно `campaigns.delete` (пока не удалена).

## Полный цикл проверен 2026-10-26 (`Скрипты/direct_test_cycle.py`)

В той же кампании: группа 5815187673 «Тест API» (регион 1), объявление 1925224843543345123, ключ 58314507299 «тест апи груминг». Всё читается обратно, кампания осталась DRAFT/OFF.

- `adgroups.add` и `keywords.add`/`keywords.suspend` работают штатно.
- **`ads.add` создаёт не текстовое, а «комбинаторное» объявление:** предупреждение 10251 «Создание текстовых баннеров закрыто. Баннер был добавлен как комбинаторный». Объявления через API теперь создаются в новом формате; как он выглядит и показывается в кабинете, не смотрели.
- **`ads.suspend` на черновике даёт ошибку 8300** («Объявление является черновиком и не может быть остановлено»): черновик и так выключен, паузу ставить не нужно. Пауза на не-черновике не проверена.
- **Ставки при автоматической стратегии не применяются:** `keywords.add` с `Bid` и `keywordbids.set` отвечают предупреждением 10160 «Ставка не будет применена, так как установлена автобюджетная стратегия». Значение 30 ₽ осталось записанным, 35 ₽ не применилось. Для ручной ставки нужна кампания с ручной стратегией (не проверено, меняет стратегию кампании, отдельное «да»).
- Имя поля у `keywordbids.set`: `SearchBid` (в единственном числе), с `SearchBids` ошибка 8000.

## Не проверено

- Минус-фразы, `campaigns.update`/`campaigns.delete`/`campaigns.resume`, отправка на модерацию, правка и пауза не-черновиков, ручная стратегия ставок.
- Срок жизни токена (OAuth Яндекса обычно 1 год, дата выдачи неизвестна).

## Ограничения API независимо от прав

- Товарная галерея / товарный мастер не отдаётся и не правится через API: [[Товарная-галерея-Мастер-кампаний-недоступность-в-Campaigns-API]].
- Новые кабинеты через Calibri дают 8800, пока redbird.analytics не добавлен представителем (`REFERENCE.md`, раздел «Яндекс.Директ — агентский доступ»).
