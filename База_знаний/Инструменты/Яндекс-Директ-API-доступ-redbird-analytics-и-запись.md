# Директ API: доступ redbird.analytics и управление кампаниями

## Проверено 2026-10-26 (только чтение, по токену из `google-cloud-jobs/REFERENCE.md`)

- Токен рабочий, это боевой доступ (не песочница): суточный лимит баллов 120 000 на кабинет Груминг - Северная 3; у других клиентов свои лимиты (168 000 – 1 947 500), лимит зависит от кабинета клиента.
- Сервис `agencyclients` отвечает **54 «Нет прав для доступа в агентский сервис»**: redbird.analytics не является агентством в смысле Директа, это **представитель** в кабинетах клиентов. Списка клиентов по токену не получить, каждый кабинет подключается отдельно через `Client-Login`.
- В 13 активных кабинетах листа «Директ» права `EDIT_CAMPAIGNS`, `IMPORT_XLS`, `TRANSFER_MONEY` = YES. Но токен redbird.analytics стоит только у 2 активных (Груминг - Северная 3, Транзит); у остальных 11 в листе токены самих клиентов, это права владельца, не наши.

## Не проверено

- Реальная запись (`campaigns.add/update`, `ads.add`, `keywords.add` и т.д.): не пробовали, по протоколу записи нужен план и «да». Права `EDIT_CAMPAIGNS=YES` на запись указывают, но не доказывают.
- Срок жизни токена (OAuth Яндекса обычно 1 год, дата выдачи неизвестна).

## Ограничения API независимо от прав

- Товарная галерея / товарный мастер не отдаётся и не правится через API: [[Товарная-галерея-Мастер-кампаний-недоступность-в-Campaigns-API]].
- Новые кабинеты через Calibri дают 8800, пока redbird.analytics не добавлен представителем (`REFERENCE.md`, раздел «Яндекс.Директ — агентский доступ»).
