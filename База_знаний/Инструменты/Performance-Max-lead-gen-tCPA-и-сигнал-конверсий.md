# Performance Max для лидогенерации: tCPA, частота правок, какую конверсию учить

Источники: официальная справка Google Ads (страница «Performance Max best practices for lead generation», support.google.com/google-ads/answer/13775965, открыта целиком 2026-10-08) и выдача поиска по профильным блогам (только пересказы в выдаче, сами статьи не открывались — отмечено ниже). Статус «не протестировано»: на наших кампаниях проверено только то, что указано в разделе «Сверка с ProfiMet».

## Из официальной справки (дословные цитаты, проверено)

- «allow at least 1-2 weeks (or up to 6 weeks for more complex setups or low conversion volume) for your campaign to run» — прежде чем оценивать/менять.
- «A tCPA set too low can limit performance.» и «a target set too high can limit impressions and conversions.»
- «Select a conversion goal closest to a sale or closed deal that has at least 15 conversions in the last 30 days.»
- «Optimize to deeper funnel conversion actions where possible.»
- Для лидогенерации — цели вида Contact / Submit Lead Form / Book Appointment / Request Quote / Qualified Lead / Converted Lead. Клика по номеру в списке нет.
- Если главная цель — объём лидов: Maximize conversions (conversion-based Smart Bidding).

Не применимо к ProfiMet: страница «Best practices for pay-per-lead goals» (answer/17326561) — для локальных услуг с профилем Google Business, ручные ставки там недоступны; ProfiMet — производитель с интернет-продажами.

## Из выдачи поиска (пересказ, не открыто в оригинале — проверять)

- Не вносить частые и крупные правки бюджета, стратегии, tCPA и таргетинга в период обучения (формулировка из пересказа справки).
- С января 2026 в PMax доступна отчётность по каналам (Search, Shopping, Display, YouTube, Discover, Gmail, Maps) — клики, конверсии, стоимость; поисковые темы — до 50 на группу ассетов; до 10 000 минус-слов на кампанию; исключения брендов; цель «новые клиенты» с исключением своих аудиторий (источники: агентские блоги и Search Engine Land в выдаче; в кабинете ProfiMet наличие не проверено).
- Слабый сигнал конверсии (микро-действия, клик по номеру) раздувает отчётные цифры и уводит показы в дешёвые, но нецелевые каналы (YouTube и др.); совет — учить на более глубоком действии (звонок с минимальной длительностью, квалифицированный лид, этап CRM). Это общий совет агентских блогов, не подтверждение механизма.

## Сверка с ProfiMet (данные кабинета и Ringostat, 2026-10-08)

- `pmax1_test` (Maximize conversions с tCPA): при tCPA 30–40 € (28.09–01.10) — 120–400 € расхода в день, до 264 тыс. показов в день; после правки 02.10 (tCPA 40 → 15, бюджет 600 → 200, пауза и возобновление) — 1.7–3.2 тыс. показов в день, потеря показов по рейтингу 76–81%. Совпадение по времени полное, механизм совпадает с цитатой Google; сезонность и выходные как альтернатива не исключены полностью (см. [[../../Клиенты/ProfiMet/Кампании/РСЯ_КМС/pmax1_test]], если запись заведена).
- Частота правок: за 30 дней у `pmax1_test` 9 правок tCPA, у `pmax01` 4 включения/паузы — против рекомендации ждать 1–2 недели.
- Клик по номеру как цель: у `pmax01` в сентябре 2026 по Ads 12 конверсий, по Ringostat по её пулу 0–1 звонков (14.09–07.10: 0). Подтверждает, что в нашем аккаунте клик по номеру плохо отражает звонки (см. [[../../Клиенты/ProfiMet/Решения]], записи 2026-09-30 и 2026-10-07).

## Структура групп ассетов: «4 группы на пробу» (no signal / search themes / competitors / interests)

- Официально (проверено 2026-10-08): поисковые темы — до 50 на группу, приоритет как у фразового и широкого соответствия в Search ([страница](https://support.google.com/google-ads/answer/14767319?hl=en)); аудитории-сигналы — не жёсткий таргетинг, показы возможны вне сигнала ([страница](https://support.google.com/google-ads/answer/14530785?hl=en)). Про «пересоздание копии» и про схему из четырёх групп в справке ничего нет.
- Из выдачи (пересказ, не открыто): схема «с поисковыми темами против контроля без них» и «конкуренты через кастомную аудиторию» встречается в агентских блогах как тестовая рамка; практики критикуют дубли групп с теми же ассетами — другая группа нужна, чтобы проверять разные ассеты, а не разные сигналы. «Пересоздание копии помогает» как рекомендацию не нашёл.
- Что видно на ProfiMet (`pmax1_test`, 01.09–08.10): группа `search themes` (42 темы) даёт 51% расхода и около 74% конверсий при CPA 26 €; `competitors` 49 €; три слабые группы (`no signal`, `зп`, `ци`) 70–172 € на 1–3 конверсии (малые выборки). Дубль `search themes_copy1` поставлен на паузу 2026-10-08. Правило оценки групп: расход от ~3× цели по CPA и CPA выше 2× цели — пауза, но после 14 дней без правок кампании. Статус: не протестировано.

## Минус-слова и отчёты по запросам в PMax; инсайты аудитории через API

- **Минус-слова в PMax** (страница [Add negative keywords to campaigns](https://support.google.com/google-ads/answer/7102995?hl=en-GB) и [Search terms report in Performance Max](https://support.google.com/google-ads/answer/16327396?hl=en-GB), проверено 2026-10-08): действуют только на инвентарь Search и Shopping; для Display и видео вместо них — исключаемые ключевые слова контента (Content Suitability); на уровне аккаунта лимит 1 000 минус-слов. Из выдачи (не открыто): на уровне кампании до 10 000, типы соответствия широкое/фразовое/точное.
- **Отчёт по запросам PMax**: в интерфейсе «Search terms and landing pages for Performance Max» (с конверсиями, кликами, показами; из него можно добавлять минус-слова). Через API у ProfiMet отдаётся только отчёт по категориям запросов `campaign_search_term_insight` (метка категории, показы, клики, конверсии за 30 дней, метка «пустая» = всё прочее); `search_term_view` для PMax пуст (см. [[Search-Term-View-ограничения-Shopping-Performance-Max]]).
- **Инсайты аудитории через API (`AudienceInsightsService.GenerateAudienceCompositionInsights`)**: у `InsightsAudience` есть поле `user_list`, но для Польши API отвечает `Location [2616] is not supported for insights` — получить индексы интересов для списка «All Converters» (id 8637533896, RULE_BASED) или CRM-списка (9441800617) через API по Польше нельзя. Брать из интерфейса Audience Manager → «Your data insights» (скриншотом).
