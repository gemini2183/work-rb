# Merchant Center: добавление товаров в ручной XML-фид

Источник знания: прямая проверка на реальном кабинете
[[../../Клиенты/EkspertAgro/Мерчант/index|EkspertAgro — Мерчант]] (серия
скриншотов источника `google_merchant_feed_new.xml`), не пересказ внешних
статей. **Статус — протестировано** в части UI-механики загрузки; сам процесс
формирования содержимого XML-файла (кто и как правит товары до загрузки) для
этого клиента ещё не выяснен отдельно.

## Как распознать этот тип источника

В "Источники данных о товарах" → карточка источника показывает:

- **Тип: "Файл (вручную)"** — ключевой признак. Означает, что Google НЕ
  забирает файл сам ни по URL, ни по SFTP-расписанию — файл нужно
  загружать руками через интерфейс.
- Рядом с этим типом всё равно присутствуют кнопки **"Обновить"** и
  **"Обновить через SFTP"** — они ведут к двум разным механизмам (см. ниже),
  и наличие кнопки SFTP не означает, что SFTP реально настроен и
  используется.
- На вкладке "Настройки источника данных" → "Показать дополнительные
  параметры" — если там нет полей адреса/пути SFTP-сервера (только
  разделитель, кодировка, кавычки, валюта, правило для идентификатора), то
  расписание получения через SFTP не настроено, и реальный путь загрузки —
  ручной.

## Процесс добавления товаров

1. Открыть источник данных → вкладка **"Настройки источника данных"** —
   убедиться, что это "Файл (вручную)".
2. Подготовить обновлённый XML-файл: взять текущую версию (или получить от
   того, кто её ведёт) и добавить новые `<item>` с обязательными полями:
   `g:id`, `title`, `description`, `link`, `g:image_link`,
   `g:availability`, `g:price` (валюта не задана по умолчанию — указывать
   явно в каждой строке, например `100.00 PLN`), `g:condition`, `g:gtin`
   или `g:mpn`+`g:brand`, `g:google_product_category`.
3. Нажать синюю кнопку **"Обновить"** (не "Обновить через SFTP" — та кнопка
   предназначена для случая, когда файл реально лежит на SFTP-сервере
   Merchant Center и его нужно просто перечитать, что не тот сценарий).
4. В диалоге "Выберите файл для загрузки" — перетащить/выбрать новый XML.
   Есть чекбокс **"Загрузить файл в тестовом режиме"** — полезно включать
   при первой проверке структуры/атрибутов нового файла, чтобы новые товары
   не начали показываться до проверки точности данных.
5. Нажать "Загрузка".
6. Проверить результат на вкладке "Последнее обновление" — там отдельно
   показывается счётчик **"Добавлено новых товаров"** (в отличие от
   "Всего обновлено товаров" — это число включает и уже существующие
   позиции, которые просто обновились по атрибутам).

## Важные нюансы

- Кнопка "Обновить через SFTP" здесь, скорее всего, нерелевантна — это
  отдельный путь для источников, где расписание получения файла настроено
  через SFTP (адрес/логин видны в дополнительных параметрах). Если этих
  полей нет — используется только ручная загрузка.
- Максимальный размер файла — 4 ГБ, форматы — `.txt` (с разделителем
  табуляцией), `.xml`, `.tsv`.
- Не путать этот ручной источник с автоматическим источником "Найдено
  Google" (сканирование сайта по schema.org/Open Graph) — это два
  независимых механизма добавления товаров в один и тот же Merchant Center
  аккаунт, с разной логикой обновления. См. запись в
  [[../../Клиенты/EkspertAgro/Мерчант/Решения|Решения — EkspertAgro (Мерчант)]].

## Открытый вопрос (не выяснено)

Как формируется содержимое самого `google_merchant_feed_new.xml` до
загрузки — вручную правится текст/таблица, или экспортируется откуда-то
(1С, склад, другая CMS) — на момент записи не установлено. Уточнить при
следующей необходимости добавить товары.
