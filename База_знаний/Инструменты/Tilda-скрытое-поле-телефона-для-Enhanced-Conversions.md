# Tilda: скрытое поле телефона для Enhanced Conversions

## Контекст

При настройке ручного метода расширенного отслеживания конверсий (Enhanced
Conversions, см. [[Расширенные-конверсии-Google-Ads-ручная-настройка]]) через блок
"Указать селекторы CSS или переменные JavaScript" в теге Google (GTM) нужен
стабильный CSS-селектор поля с номером телефона.

## Находка

Видимое поле телефона на форме Tilda с маской ввода (`type="tel"`,
`class="t-input t-input-phonemask"`) имеет **нестабильный** `id` вида
`input_1496239478607` — генерируется Tilda и не гарантированно переживает
пересборку блока.

Но рядом с каждым таким полем Tilda **автоматически** создаёт связанное
**скрытое** поле, куда JS сам складывает уже собранный полный номер (с кодом
страны):

```html
<input type="hidden" name="phone" class="js-phonemask-result js-tilda-rule">
```

Имя обычно `name="phone"`, но встречается и `name="Phone"` (с заглавной буквы) —
подтверждено на разных формах одного и того же сайта (mocnaszklarnia.pl,
клиент Poliweglan), поэтому имя не является 100%-но гарантированной константой
для любого сайта на Tilda — стоит проверять на каждом конкретном клиенте.

## Практический вывод

Для CSS-селектора в Enhanced Conversions использовать не `id` видимого поля, а:

```
input[name="phone"]
```

(или `input[name="Phone"]`, если на конкретном сайте используется такое
написание — проверять через DevTools/автоматический обход форм).

Это устойчивее к правкам вёрстки на Tilda, чем привязка к автогенерируемому `id`,
и даёт уже нормализованный номер с кодом страны, а не сырое значение из
маскированного поля ввода.

## Как проверять на новом клиенте

Пройтись по всем страницам сайта с формами (через DevTools или автоматический
обход) и выписать все `<input>` с `type="tel"` — у каждого рядом должен быть
скрытый `input[type=hidden]` с классом `js-phonemask-result`. Смотреть, какое
у него `name` — не считать по умолчанию, что это всегда `phone`.

## Статус

Не протестировано на практике в GTM — CSS-селектор ещё не подтверждён по факту
срабатывания хэш-совпадений (`em`/`ph` параметр в теге). Обновить после первой
проверки через Tag Assistant на клиенте Poliweglan.
