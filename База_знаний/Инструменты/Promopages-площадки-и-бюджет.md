## Места показа

[справка: `advertising-show`, `commercial-coverage`]

| Вариант | Что даёт | Обязательные настройки |
|---|---|---|
| Только РСЯ | показ как рекламное объявление (обложка, заголовок, описание, до 4 быстрых ссылок) на сайтах и в приложениях РСЯ; доступны интересы и привычки | изображение обязательно |
| РСЯ и Поиск | оба набора заголовков/описаний (отдельный для каждой площадки) | минус-фразы, упоминание бренда |
| Только Поиск | показ по запросам Яндекса; изображение технически обязательно, но не показывается | минус-фразы, упоминание бренда; автотаргетинг выключить нельзя |

- Менять место показа в запущенной кампании можно: «Кампании → Текущие → Настройки → Таргетирование → Места показа публикаций». [справка]
- **Лента Дзена как отдельный вариант выбора в справке и API не фигурирует** (`placements` = `rsya`, `search`). Практики описывают Дзен как отдельный продукт (кабинет в VK Реклама), см. Habr 2024; Kokoc 2026 включает «ленту Дзена, Карты, Маркет, КиноПоиск» в список площадок. Расхождение: справка и API не выделяют ленту Дзена; поисковый сниппет другого практического источника (Т-Банк, раздел о рекламе в Дзене/ПромоСтраницах) говорит, что в РСЯ «входит лента Дзена». Возможное объяснение: Дзен — один из партнёрских сайтов РСЯ, отдельной настройкой его выбрать нельзя. Проверка: отчёт Метрики по `ym:s:referalSource`/домену источника для визитов с `utm_source=yandex.promopages` (доля `dzen.ru`). [справка + практики; не проверено на практике]
- **Что включать/исключать:** выбор конкретных сайтов РСЯ и списка исключаемых площадок в справке по ПромоСтраницам **не описан** [в источниках нет]. (Поисковая выдача по «до 1000 площадок» относится к Директу, не к ПромоСтраницам; переносить нельзя.)
- Охват по оценке самих площадок: РСЯ ~90+ млн в месяц, с Поиском 100+ млн (ppc.world 2025); 96 млн в месяц и до 63 млн посещений в день (Kokoc 2026); Habr (2024): РСЯ >50 тыс. площадок. [практики, цифры самих площадок, не проверено]
- Наши данные: из 36 кампаний `rsya` — 32, только `search` — 3, `rsya`+`search` — 1. [наши данные: `targeting.placements`]
- Практика Sostav/Vitamin.tools (26.02.2026): объединение Поиска и РСЯ в одной кампании отдаёт бюджет более дешёвым кликам РСЯ и «съедает» поисковый спрос; поиск и РСЯ лучше вести отдельными кампаниями с отдельным дневным лимитом; ориентиры CTR: Поиск около 5%, РСЯ 2-3%. [практики, один кейс окон/дверей]

### Поиск: автотаргетинг и минус-фразы

[справка: `advertising-show`]
- «Автотаргетинг» на Поиске анализирует заголовки и статью и подбирает публикацию под запросы; поэтому нужны разные заголовки (ppc.world 2025: до 15 текстовых заголовков).
- Категории запросов: целевые, узкие, широкие, сопутствующие, альтернативные; в новых кампаниях по умолчанию включены целевые и узкие.
- «Оптимизация текстов под поисковый запрос» (YandexGPT адаптирует заголовок и описание под запрос) — по умолчанию включена во всех кампаниях.
- Минус-фразы: не более 7 слов в фразе; порядок — запуск без минусов на 1-2 недели → отчёт «Статистика → По поисковым запросам» (только при показах на Поиске, период до 90 дней) → минусы по запросам без конверсий или с дорогой конверсией. Не копировать минуса из рекламы на Поиске и не ставить в минус бренд и слова из заголовка.
- Для нашего клиента из этого следует: перед Поиском-тестом нужна отдельная кампания и счётчик/цель в отчёте по запросам. Это тест на будущее, не текущий режим (в октябре активна 2602-1, РСЯ). [наши данные, `Хроника_2026-10`]

## Бюджет и лимиты

[справка: `commercial-coverage`, `types`, `workflow`]

- **Дневной лимит**: «средний лимит в день» (от 1 000 ₽) для ставочных стратегий; после исчерпания показ приостанавливается до следующего дня. Для дневного бюджета алгоритм может превысить лимит до +35% в отдельные дни, но средний расход за неделю равен заданному. (MediaGuru 2024 называет отклонение «до 25%» — расхождение двух источников, вероятно разные годы; справка новее.) [справка + практики]
- **Лимит на кампанию** («максимальный бюджет»): от 3 000 ₽ для ставочных стратегий; после исчерпания кампания приостанавливается, для возобновления поднять не менее чем на 3 000 ₽ и при необходимости пополнить счёт. Нужен, чтобы ограничить расход; в API это `maxMoney`.
- **Бюджет на период**: от 10 000 ₽, период от 3 дней (советуют 7-14; MediaGuru: от 3 до 90 дней), **ни бюджет, ни период менять после запуска нельзя**. Для стратегий «на период» рекомендаций по оптимизации в кабинете нет.
- **Темп расхода**: красный индикатор в блоке бюджета сигнализирует о близком исчерпании дневного или общего лимита; блок рекомендаций под графиками предлагает изменить ставку/бюджет и показывает прогноз роста.
- **Недорасход — не лимит**: наши кампании тратили 1,7-18,1% дневного лимита (30 дней до 2026-08-25), в октябре 2602-1 «освоено 4%» при среднем лимите 2 227,2 ₽ в день. Лимит не был узким местом; причина — малое число засчитываемых действий и ставка (см. [[Promopages-стратегии-и-оплата]]). [наши данные: `Решения.md` 2026-08-25 и 2026-10-27]
- В нашей структуре у части кампаний нет `maxDailyMoney` (6 кампаний), у шести есть `maxMoney` 200-300 тыс. ₽ (кампании 2024). [наши данные]

### Прогноз бюджета и объём тестов

- В кабинете (Россия) есть раздел «Прогноз бюджета»: категория, размещение, гео, пол/возраст, месячный бюджет → «эффективный бюджет в месяц» по усреднённым данным клиентов; выгрузка `.xlsx`. Для франшиз нужна ли отдельная категория и какие значения — неизвестно [в источниках нет]; смотреть в кабинете и сохранить в xlsx. [справка: `projection-budget`]
- По статистике Яндекса у лучших рекламодателей 15-20 активных статей одновременно; Habr (2024): тестировать не меньше 3 статей, в идеале 9 за первые 3 месяца, бюджет менее 150 000 ₽ — риск не набрать статистику; Kokoc: 70/30 между лучшим вариантом и тестами. [справка + практики, цифры не из нашей ниши]

## Период, старт и «Завершение»

[справка: `commercial-coverage`, `workflow`]

- **Старт кампании**: дата, по московскому времени (UTC+3), после модерации и при наличии денег на счёте; иначе запуск после пополнения и модерации.
- **Период кампании** (даты старта и окончания) редактируется в «Настройках → Основные». «Завершение» в наших записях — это дата окончания периода; 31.10.2026 для 2602-1 — так записано в `Хроника_2026-10`. Продление = смена даты окончания в «Настройках». Что происходит ровно в момент окончания (статус «Остановлена» или «Завершена») и можно ли возобновить такую кампанию без копирования — справка прямо не говорит; в справке есть статусы «Текущие / Остановленные / Архивные» и «Планируется» для отложенного старта. [справка + [в источниках нет] про окончание]
- **Пауза до даты**: в «Настройках» указать дату возобновления → статус «Планируется», запуск в эту дату.
- **Остановка** занимает 10-60 минут (в среднем ~30); в архив можно перевести только новую или остановленную; статистика архивных формируется до 3 дней. [справка]
- **Статус в API**: кампании не отдают статус (`isArchived` есть только для архива). Для «активна/остановлена» нужен скриншот «Текущие». [справка + наши данные, `Решения.md` 2026-08-25]

## Счёт, пополнение, баланс

- Для всех кампаний один счёт. Пополнение: «Кампании → Пополнить», выставляется счёт через Яндекс Баланс; физлица — карта или квитанция, юрлица — счёт по платёжному поручению. Зачисление: по карте в течение 15 минут, банковским платежом 2-3 рабочих дня; в кабинете сумма указана без НДС. [справка: `payment/account`]
- **Минимальный первый платёж**: справка — **80 000 ₽ без НДС** (Россия), 3 000 BYN, 450 000 KZT; для физлиц по карте первый платёж невозможен (по карте за раз не более 49 999,99 ₽, остальное квитанцией). Скидка на первый платёж после экспресс-курса — только прямым клиентам без агентства. Kokoc (31.03.2026) называет иное: первое пополнение от 20 000 ₽, последующие от 5 000 ₽. Расхождение, вероятная причина: условия акций/пакетов или старая цифра; для нас важнее, что минимальная сумма **последующих** пополнений в справке не названа. [справка + практики; не проверено на практике]
- **Общий счёт Директа и ПромоСтраниц** (только Россия, не для агентств): единый баланс, логин в двух сервисах должен совпадать; для подключения баланс ПромоСтраниц должен быть 0 ₽; после подключения разделить счета нельзя; в Директе появляется автоматическая кампания (не переименовать, не остановить), статистика ПромоСтраниц остаётся только в их кабинете. [справка: `payment/shared-account`]
- **Возврат**: по каждому оплаченному счёту отдельно, по заявке; физлицам после подтверждения личности. [справка: `payment/refund`]
- **Баланс по API**: `GET /publishers/balances?publisherIds=…` (не `publisherId`; идентификаторы кабинетов даёт `GET /permissions/user`). Первый запрос с неверным именем параметра дал 400 (см. `Решения.md` 2026-10-27). [справка + наши данные]
- В кабинете не видно истории баланса и действий; API отдаёт только текущий баланс. [наши данные: `Решения.md` 2026-08-25]
- Расход в отчётах API (`budget`) указан **без НДС**; в кабинете можно показывать «с НДС» и «с учётом скидки». Сверять кабинет с Метрикой/API нужно по одной базе. [справка: API `get-reports`, `statistics/extended`]

### Что происходит при нехватке денег

- Кампания стартует только «если будут деньги на счёте»; без денег кнопка «Настроить обложку и сохранить» при привязке статьи недоступна. [справка]
- **Что делает уже идущая кампания, когда баланс обнулился**, в справке не описано: остановка, пауза показов или перерасход до пополнения. [в источниках нет] Для 2602-1: баланс 4 529,67 ₽ на 27.10 при расходе 700-1 100 ₽/день до 16.10 и «Завершение» 31.10; проверить после 31.10 по скриншоту и по `campaigns-daily-stats`. [наши данные, `Хроника_2026-10`]
- Провал показов 2-8.08.2026 у нескольких кампаний одновременно — правдоподобные причины (баланс, лимит, частые правки ставки) проверить нечем: истории баланса и действий нет. [наши данные]

## Что проверить / вопросы

1. Скриншот блока «Бюджет» и «Основные настройки» кампании 2602-1: тип стратегии, лимиты, дата окончания, состояние галочки быстрых действий.
2. Остановилась ли 2602-1 31.10 и пополнен ли счёт; это самая быстрая проверка «поведения при нехватке денег» на реальных данных (лог `campaigns-daily-stats` за 1-13.11).
3. Сохранить в xlsx «Прогноз бюджета» по категории клиента (если категория есть).
4. Условия последующих пополнений и скидок для нашего аккаунта (прямой или агентский).
