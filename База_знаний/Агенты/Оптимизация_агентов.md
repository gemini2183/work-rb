# Оптимизация агентов: где мы и что дальше

**Как использовать.** В сессии «займёмся оптимизацией агентов» читать только этот файл, затем по ссылкам из раздела 6. После каждой сессии оптимизации дописывать разделы 3–7 (а не только журналы клиента). Журналы (Хроника, Журнал_изменений) ссылаются сюда.

## 1. Цель и критерии
- Не терять лимит Claude Code на груз до первой команды и на перечитывание журналов.
- Критерий готовности (П-016): агент-исполнитель получает **бриф**, а не список «прочитай всё»; последний контекст агента < 100 тыс., вес < 1 млн (`python Скрипты/claude_usage.py --agents --session <id>`).
- «Вес» — сравнительная мера из шапки `claude_usage.py` (ввод 1,0; запись кэша 1,25 / 2,0; чтение кэша 0,1; вывод 5,0). Множитель вывода для Sonnet 5.5 не проверен.

## 2. Исходная картина (панель `/usage` 11.11, Хроника Landver, запись «закрытие сессии» 12:45)
Длинные сессии 72 % расхода, общие агенты 20 %, `CLAUDE.md` (~6 тыс. токенов на каждый запрос) 21 %.
Стартовый груз сессии: `CLAUDE.md` 42 КБ, `MEMORY.md` 27 КБ / 172 строки (хук 11.11 просит ужать до 140), описания инструментов. Стартовые 55 тыс. токенов — груз до первой команды агента (замер 11.11).
Журналы Landver весят 1,15 МБ (Журнал_изменений 341 КБ, Решения 303 КБ, Задачи 144 КБ, Хроники 264 КБ, Паспорт 6,6 КБ): целиком их читать нельзя (П-018).

## 5. Что получилось и что нет (только установленное)
**Получилось:**
- Разведчик Ped+Bike: вес 458 тыс. против ≈2,65 млн у исполнителя 3 (задачи разные: разведка и сборка кампании), контекст до 133 тыс. вместо 224 тыс. Критерий «контекст < 100 тыс.» не достигнут, «вес < 1 млн» достигнут.
- Планировщик выдал точный план: нашёл блокер по меткам ссылок и три расхождения Паспорта с кабинетом; запись по его командам прошла без ошибок плана (одна моя: запуск скрипта не из папки `Скрипты`, до записи).
- Запись в кабинет супервайзером по плану, с «да» по пунктам и чтением обратно.

**Не получилось / открыто:**
- Агент записи в вики остановился, не закончив (П-020).
- Стартовый груз 55 тыс. не разбирался, `CLAUDE.md` и `MEMORY.md` не сокращены (правки `CLAUDE.md` — только по «да» пользователя).
- Раздела «Действующие решения» в Паспорте нет, значит брифы всё ещё могут тянуть журналы (П-018).
- Не проверено: стоимость возвратов агента, протухает ли кэш при простое, видят ли агенты `MEMORY.md`.
- Универсального `gads_campaign_builder.py --plan` нет (для правок кампаний не нужен, хватает готовых скриптов; нужен только для новых кампаний).
