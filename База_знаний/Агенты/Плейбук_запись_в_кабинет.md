# Плейбук: запись в рекламные кабинеты (для исполнителя)

Источник: раздел «Протокол записи в рекламные кабинеты» CLAUDE.md (решения 2026-10-06, 2026-10-26). Запись только по «да» владельца (конституция, разделы 4–5).

1. **План в таблице, ничего не пишу.** `Объект | Действие | Было → Станет | Откуда факт`. Для текстов объявлений: `Поле | Текст | Знаков/лимит | Откуда факт`.
2. **Блок «Допущения (проверить)»:** всё, что выбрано по умолчанию (расписание, URL, гео, галочки).
3. **Факты в текстах** (подарки, цены, сроки, акции) только из свежих источников клиента, присланных в сессии, не из старых кампаний аккаунта.
4. **До «да» максимум `validate_only`.** После «да» писать только скриптами из `Скрипты/` с `--execute`; разовые curl и питон-цепочки не использовать. Ключи в файлах не писать.
5. **Новые кампании всегда на паузе.** Включение отдельным «да».
6. **Что считается записью:** создание, изменение, удаление кампаний, групп, объявлений, ключей, минус-слов, аудиторий; смена бюджета, ставок, стратегии, статуса.
7. **После записи прочитать обратно из аккаунта** и показать фактическое состояние. Затем записать в `Клиенты/<Имя>/Решения.md` и `Клиенты/<Имя>/Журнал_изменений.md` (было → стало, снимок «до», проверка, откат, когда мерить эффект).
8. **Смена посадочной** (конечного URL объявлений): в том же ходе, до «готово», проверить всё, что показывается с объявлением: быстрые ссылки (адрес, якорь, не про другой продукт), звонковый ассет (номер в пуле Ringostat новой страницы), сниппеты, callouts, промо, картинки и тексты против страницы. Читать `campaign_asset` и `ad_group_asset`; групповые ссылки через `Скрипты/gads_sitelinks.py`. Группы на старой странице не трогать и не ставить на паузу без просьбы.
9. **OpenAI Ads:** запись только `Скрипты/openai_ads.py` (`set-bid` без `--execute` показывает план, с ним пишет и читает обратно); ключ в переменной `OPENAI_ADS_API_KEY`, значение нигде не писать.
