# Агент ежемесячного клиентского отчёта

**Важно.** Агент отчётов уже существует отдельно. Этот файл — требования к данным, которые вики копит для него: журнал изменений (что и зачем), реестр экспериментов (основание, ожидание, итог), хроника месяца, базовые значения «до». При результате хуже ожиданий отчёт строится как «проверили гипотезу → что узнали → что делаем», без выдуманных успехов и без сокрытия.

Роль: только чтение. Вход — клиент и месяц. Выход — отчёт для клиента (аудитория — клиент, не внутренний разбор).

## Источники
- `Клиенты/<клиент>/Журнал_изменений.md`: записи месяца (`И-NNN`), поля «Зачем», «Результат на сегодня» (измерено / гипотеза / нет данных), «Для отчёта клиенту (EN)». Записи «ретро» восстановлены из `Решения.md`.
- Цифры месяца: Ads через API (расход, клики, конверсии) и Ringostat (уникальные звонки), формы (`form_submit_gtm`); план клиента — Google-таблица плана.
- `Клиенты/<клиент>/Эксперименты.md` (гипотеза, основание, ожидание, итог) и `Хроника_<месяц>.md` (связная история месяца) — логика решений и итоги; `Кампании/…` — логи кампаний; `Статистика/` — снимки.

## Алгоритм
1. Собрать цифры месяца и предыдущего периода: **объём заявок** (звонки Ringostat + формы) и **цена заявки** — главный результат в начале каждого блока; качество (коэффициент конверсии) и объяснение «почему» (показы, доля показов, CPC) идёт после.
2. План и факт: заявки, CPA, бюджет (из таблицы плана).
3. Выбрать из журнала изменения, которые повлияли на результат; для каждого взять «Зачем» и строку EN, переписать на понятном клиенту языке: что сделали, зачем, какой эффект измерен. Гипотезы клиенту как результат не подавать.
4. Оформить по правилам формата: таблица с цифрами (было → стало, %) сначала, потом короткие вывод и буллеты; от общего к частному (проект → тип кампаний → кампании); без внутренней кухни («важная поправка», методология сверки, стоп-правила тестов); малые тесты отдельным разделом не выносить, если не меняют вывод.
5. Проверка перед отправкой: есть ли в каждой секции объём, стоимость и качество вместе; нет ли гипотез в роли фактов; совпадают ли числа с источниками; указан ли период и срез.

## Ограничения данных, которые агент обязан знать (ProfiMet)
- Клик по номеру завышен (в 4.8 раза чаще звонков); заявки считаем по Ringostat и формам, не по конверсиям Ads.
- Ads видит около 85–90% звонков по PMax (сентябрь 2026); потеря на пути Ringostat → GA4 зависит от cookie-баннера.
- Звонки по статическому каналу «Calls from Ads» не привязываются к кампании.
- Язык отчёта по умолчанию — язык клиента; строки EN в журнале — черновик формулировок; язык уточнить у пользователя.
