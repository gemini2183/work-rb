# Быстрый осмотр Директа потенциального клиента

Цель: за одну сессию понять, стоит ли углубляться в полный аудит, и собрать вопросы клиенту (через начальника). Полный аудит не запускается, пока нет ответов.

## Порядок
1. **Токен клиента — файл вне vault** (`C:\Users\<user>\AppData\Local\Temp\<имя>.token`), не в чат, не в таблицу агентства, не в переменную окружения. Проверять размер файла (пустой файл и расширение `.txt` от Блокнота — частая ошибка), содержимое не открывать. После аудита файл удалить (`--delete-token` или вручную) и проверить, что его нет.
2. `Скрипты/direct_express_audit.py --login … --token-file … --client-folder …` — кампании (все статусы, архив), настройки, статистика, запросы бренд/небренд, структура, фиды.
3. **Цели читать в двух местах:** `PriorityGoals` и `GoalId` в стратегии (13 = ключевые цели из `PriorityGoals`). Названия целей из API не получить — скриншот настроек кампаний (по одному на каждый счётчик).
4. **Гео** — из `RegionIds` групп объявлений (`adgroups.get`), расшифровка через `dictionaries.get` (`GeoRegions`), а не по названию кампании.
5. **Статус обучения стратегии через API не виден** — не утверждать «обучена/не обучена», писать «API не отдаёт»; со скриншота интерфейса — только с пометкой источника.
6. Сравнение двух кампаний — за одни и те же даты, по общей цели. Разные стратегии не причина отказаться; причина — цели на разных счётчиках без подтверждённого общего смысла.
7. **Каждое число отчёта — из скрипта.** Свериться скриптом по образцу `Скрипты/novotel_express_numbers_check.py` (числа документа против сырых CSV).
8. Смысл цели не домысливать («Квал MICE» — только название, расшифровка у клиента).
9. Документ начальнику: безлично, Google Документ; первым идёт вывод простыми словами без деталей по отдельным кампаниям; результаты кампаний — отдельной таблицей на каждую кампанию, рядом с расходом всегда цена заявки.

## Ловушки (из сессии)
- Слияние отчётов Директа по ключу размножало строки — суммировать строки с одинаковым ключом перед слиянием.
- Отчёты Директа: не чаще 1 запроса в 10 секунд (ошибка 56).
- `feeds.get` требует `Ids`; идентификатор фида — со скриншота или из групп с `FeedId`.
- Drive-коннектор не правит текст в готовом Google Документе: каждая правка = новый файл; старые удалять только по просьбе пользователя.
