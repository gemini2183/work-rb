# План переноса кампании и квота API

**Почему.** 10.11.2026 при копировании 1 699 минусов основной кампании Landver в LA+BH упёрлись в суточный лимит basic access ([[../Проблемы/П-001_лимит-операций-google-ads-api]]). Скопировано 1 430 из 1 699 (в кампании 1 435 с пятью перекрёстными), 269 не хватало, а что съело остаток дня, не знали: счётчика не было.

## Что известно о лимите (внешние источники, 2026-11-11; на нашем токене не сверялось)
- Basic access — 15 000 операций в день на токен, standard — без суточного потолка (developers.google.com/google-ads/api/docs/access-levels). Заявка на standard — задача в `Задачи.md` (корень).
- Операция: каждый элемент mutate = 1; `search` / `search_stream` = 1 за запрос, не за строку; отклонённый запрос тоже считается (docs «quotas», rate sheet). Один mutate — не больше 10 000 операций. Порции квоту не уменьшают, они нужны для возобновляемости.
- Не установлено: тратит ли квоту `validate_only`; считаются ли чтения так же, как записи (вчера лимит закрыл и чтение).
- Общие списки минусов: 20 на аккаунт, 5 000 слов в списке (help 6372658; в 2025 были сообщения о временном снижении лимита до 1 000 и о списках чуть больше 5 000).
- Google Ads Editor: расходует ли он квоту нашего токена — источников не нашли, **не проверено**.

## Шаг «план переноса» (до таблицы «было → станет»)
1. `python Скрипты/gads_clone_plan.py --customer-id <ID> --source <id кампании-источника> [--target <id уже созданной>] [--also N] [--client-folder <Имя>]` — только чтение, около 10 запросов на кампанию. Снимок источника уходит в `Клиенты/<Имя>/Статистика/clone_plan_*.json`.
2. Скрипт печатает: состав источника (минусы по типам, гео, группы, ключи, объявления, ассеты), чего не хватает в цели, **Решение 1** (остаток в уже созданную кампанию) и **Решение 2** (следующие кампании с тем же списком), затем итог операций и расход сегодняшнего дня по журналу.
3. Правило выбора для списка слов: остаток в готовую кампанию — через API (в общий список его не переложить без снятия слов с кампании); следующие кампании — общий список от 2 кампаний (N + кампании против N × кампании), при одной операций поровну; больше порога захода (допущение 2 000, параметр `--api-budget`) — порциями по дням или вручную в интерфейсе.
4. Только затем таблица «было → станет» и «да» ([[Протокол_подготовка_и_реализация]]).

## Журнал операций
`Скрипты/gads_quota_ledger.py`: `wrap_ga(ga, "имя")` считает чтения, `record_mutate("имя", n)` — записи; файл `Скрипты/secrets/gads_ops_ledger.csv`, сводка `python Скрипты/gads_quota_ledger.py --days 3`. Это нижняя оценка: веб-интерфейс, Editor и скрипты без подключения в нём не видны. Подключены: `gads_landver_search_rebuild.py`, `gads_clone_plan.py`. **Не подключены сторожа** (`gads_spend_guard_cpa.py`, цикл раз в 2 минуты, по ~300 тактов в день на клиента по логам 10.11, по несколько запросов за такт — вклад в лимит оценить нельзя, пока не подключены) и остальные скрипты — подключать при ближайшей правке, сторожам нужен перезапуск.
