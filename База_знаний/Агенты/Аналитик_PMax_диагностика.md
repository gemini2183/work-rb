# Аналитик кампании: диагностика PMax

Роль: только чтение. Вход — клиент, кампания (или «весь проект»), вопрос («почему упал объём», «где теряем деньги»). Выход — пакет решения по [[Протокол_подготовка_и_реализация]].

## Шаги и чем их делать
1. **План и факт проекта.** `read_plan` (Google-таблица «Цели2 Адвайта», лист «<Месяц> <гг>»): заявки, CPA, бюджет; факт — последний отчёт `Клиенты/<клиент>/Статистика/Отчёт_…` или `campaign_analyzer`. Посчитать разрыв (ProfiMet 10.2026: план 273 заявки / 22 €, факт сентября 142 / 30.9 €).
2. **Состояние кампаний.** GAQL по `campaign` (`status`, `primary_status`, `primary_status_reasons`, стратегия, цель по CPA `maximize_conversions.target_cpa_micros`, бюджет); `gads_campaign_settings.py` для гео, сетей, расписания; ассеты и сигналы групп.
3. **История правок со значениями.** Ресурс `change_event` (окно 29 дней), поля `old_resource` / `new_resource` для `target_cpa`, `amount_micros`, `status` (скрипт `gads_change_history.py` даёт только названия полей — значения достаём отдельным запросом).
4. **Динамика и потеря показов.** По дням и неделям: показы, клики, расход, конверсии (`segments.date`, `segments.week` с ограничением диапазона дат); `search_budget_lost_impression_share` и `search_rank_lost_impression_share`. Потеря по рейтингу при нулевой по бюджету — сигнал, что ограничивает цель по CPA или ставка.
5. **Сопоставление с правками и альтернативы.** Наложить правки на график; проверить: другие кампании в те же дни, выходные, год к году, статус кампании. Формулировка вывода — «совпадение + механизм + что не исключено».
6. **Каналы и площадки PMax.** `Скрипты/gads_pmax_channel_split.py` (сеть показа: SEARCH, DISCOVER, YOUTUBE, CONTENT); площадки — `performance_max_placement_view`; канал по видео — oEmbed YouTube; метод и подводные камни — [[../Инструменты/Performance-Max-площадки-инвентарь-и-исключения]].
7. **Запросы.** Категории `campaign_search_term_insight` (API) и полный отчёт из интерфейса «Search terms and landing pages for Performance Max» (CSV); исключить строки «Total»; решение о минусах по правилу значимости — [[../Паттерны/PMax-минус-слова-по-отчёту-запросов-значимость]].
8. **Группы ассетов.** Метрики `FROM asset_group` (с `segments.ad_network_type`); доля расхода и CPA группы; сигналы (`asset_group_signal`); правило паузы слабой группы: расход от ~3× цели и CPA выше 2× цели, не раньше чем через 14 дней без правок. Реальные звонки по группам не разбираются (Ringostat делит только по кампании).
9. **Проверка конверсий.** `segments.conversion_action_name`, `conversions` (primary) против `all_conversions`; сравнить с уникальными звонками Ringostat (`ringostat_stats_profimet.py`); коэффициент «клик по номеру / звонок» (ProfiMet: 204 против 42.5, то есть 4.8). Поправка цели: цель в Ads = реальная цель ÷ доля заявок, видимых Ads (ProfiMet по сентябрю около 88%; верно только для `pmax1_test`, считать по каждой кампании отдельно). Обязательная сверка перед выводом «кампания слабая» — [[../Паттерны/Сверка-конверсий-Директ-Метрика-Коллтрекинг]].
10. **Аудитории.** Audience Manager → Your data insights → выбрать список (скриншот пользователя; через API Польша не поддерживается); in-market индексы списка покупателей; конкуренты — Auction insights (скриншот или CSV), проверка сайтов; методика — [[../Инструменты/Google-Ads-Auction-insights-и-потеря-показов]].
11. **Практики.** Если нужен внешний факт — исследователь практик, не память; результат сразу в базу знаний.
12. **Пакет решения.** Варианты, ранжированные по уверенности (данные есть / гипотеза), для каждого — стоп-правило, дата оценки, откат; оценка арифметикой проекта (сколько заявок и по какой цене должны дать новые каналы, чтобы закрыть разрыв с планом).

## Правила анализа
- Три оси в каждом блоке: объём, стоимость, качество; не фильтровать данные молча.
- Малые выборки называть малыми (число конверсий рядом с каждой цифрой).
- Выбор цели по CPA: смотреть реальную цену конверсии той же цели; слишком низкая цель ограничивает показы (Google, справка по лидогенерации).
- Не предлагать минусовать общие запросы, пока они в сумме конвертируются.
