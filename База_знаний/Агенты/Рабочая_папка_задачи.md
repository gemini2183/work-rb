# Рабочая папка задачи

**Зачем.** Супервайзер и агенты обмениваются не пересказами в чате, а файлами. Каждый читает только свои входы и пишет только свой выход. Так контекст супервайзера остаётся тонким, а агент не раскапывает историю (П-016).

**Где.** `Клиенты/<Имя>/Работы/<ГГГГ-ММ-ДД>_<задача>/` — одна папка на задачу, создаёт супервайзер при постановке.

## Файлы и владельцы

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `00_постановка.md` | супервайзер | слова пользователя дословно, клиент, объект (адрес страницы, кампания), 3–5 строк |
| `10_данные.md` | агент **campaign-scout** | факты из кабинета и с сайта: готовность страницы, образец, объёмы, стоимость в операциях API, блокеры |
| `11_страница.md` | агент **page-check** | проверка страницы: форма, события, подмена номера, мобильный экран; первая строка «готова / не готова» |
| `20_бриф.md` | супервайзер | решения пользователя с датой, значения для плана, список файлов (≤5), «нельзя», контракт; формат — [[Шаблон_брифа_исполнителю]] |
| `30_план.md` | агент **campaign-planner** | таблица «Объект \| Действие \| Было → Станет \| Откуда факт \| Почему», команды скриптов без `--execute`, результат проверки без записи, допущения |
| `40_запись.md` | агент **campaign-executor** (или супервайзер вставляет вывод скрипта) | что записано после «да»: дата и формулировка «да», вывод `--execute`, чтение обратно, снимок «до», откат |
| `35_факты.md` | агент **fact-checker** | утверждения текстов объявлений против страницы и свежих источников клиента: статус, цитата, замена |
| `50_вики.md` | агент **wiki-recorder** | список внесённых записей (файл, раздел), что оставлено как «нет данных» |
| `Доска.md` | супервайзер | статусы направлений, «что ждёт пользователя» ([[Шаблон_доски_статусов]]) |
| `файлы/` | любой агент | тяжёлое: дампы, Excel, логи; в ответ и в файл-вывод — только путь |

## Кто что читает

| Роль | Читает | Пишет |
|---|---|---|
| Супервайзер | `Доска.md`, блок «Резюме» (первые ~10 строк) файлов `10`, `30`, `50`, ответы агентов (≤15 строк) | `00`, `20`, `40`, `Доска.md` |
| campaign-scout | `00_постановка.md`, Паспорт клиента, скрипты | `10_данные.md`, `файлы/` |
| campaign-planner | `20_бриф.md`, `10_данные.md`, файлы из брифа (≤5), справка по скриптам | `30_план.md`, `файлы/` |
| page-check | `00_постановка.md`, Паспорт клиента, справка скриптов | `11_страница.md`, `файлы/` |
| fact-checker | тексты из `30_план.md`, `20_бриф.md`, источники фактов из брифа (выгрузка страницы, Факты_сайта, `11_страница.md`) | `35_факты.md`, `файлы/` |
| campaign-executor | `30_план.md`, `20_бриф.md` («нельзя»), «Резюме» `10_данные.md`; цитата «да» в задании | `40_запись.md`, `файлы/` |
| wiki-recorder | `20_бриф.md`, `30_план.md`, `40_запись.md`, свежие записи Журнала для формата | `50_вики.md` и записи в вики клиента (Журнал, Хроника, Паспорт, Задачи) |

## Правила обмена
1. **Свой выход — только свой файл.** Чужие файлы агент не правит. Заметил ошибку во входе — пишет её в раздел «Замечания» своего файла, супервайзер решает.
2. **Шапка и «Резюме».** Каждый файл начинается с шапки (кто, когда, на основании каких файлов) и блока «Резюме» до 10 строк. Супервайзер читает только «Резюме».
3. **Ответ агента — до 15 строк:** сделано / проверено (источник, время) / не проверено и как проверить / блокеры / что нужно от пользователя / пути к файлам. Содержимое файла в ответ не переписывается.
4. **Бриф после «да» не правится.** Изменение решения — новый файл `20_бриф_v2.md`, старый остаётся.
5. **Правка плана:** мелкая — супервайзер правит `30_план.md` сам; крупная — новый короткий планировщик с путём к плану (не `SendMessage` старому).
6. **Агенты не пишут в кабинеты.** Запись только скриптом `--execute` в сессии супервайзера в режиме Manual по «да» пользователя.
7. **В вики клиента** (Журнал, Хроника, Паспорт, Задачи) пишет только wiki-recorder после `40_запись.md`; разведчик и планировщик туда не пишут.
8. **Закрытие задачи:** в `Доска.md` строка «закрыто» + ссылка на записи в Журнале; папку не удаляем (история решений).

## Чего пока не знаем
- Укладываются ли агенты в 10 строк «Резюме» и <100 тыс. токенов контекста — проверит `Скрипты/claude_usage.py --agents --session <id>` после первого прогона.
- Что именно изолировано. Контекст агента отделён по построению: чужой диалог, задачи и рассуждения другого агента или супервайзера он не видит, только своё задание и то, что сам прочитает. Что НЕ изолировано: файлы на диске. Агент технически может открыть чужой файл в папке задачи или журнал другого агента (`~/.claude/projects/*/subagents/*.jsonl`); запрет на это пока только в тексте промпта. Техническое ограничение по путям для конкретного агента не проверялось.
