# Юристы (personal injury, США): какая конверсия считается нормальной

Вопрос из сессии Landver 2026-10-19: если реальная конверсия посадочной 3%, это нормально или низко. Найдено во внешних источниках, на наших кампаниях не проверено. Все числа — оценки агентств, методика часто не раскрыта, источники между собой расходятся.

## Что нашли

- WordStream/LocaliQ, отчёт по юридическим услугам: средняя конверсия поиска у юристов 7%; категория «Accidents & Personal Injury Law» самая низкая — 5,45%; средняя цена лида по юристам $111. Страница ссылается на рост CPC за 2023, год отчёта не уточнён.
- Пересказы отчётов 2026 (The Ad Spend, Webtonic): конверсия поиска у юристов 5,05–5,55%, ниже среднего по всем нишам.
- Агентские сводки по PI: средняя конверсия сайта юриста по всему трафику 2,8–3,2%; посадочные под платный трафик 5–8%; отдельные кейсы 5,6% (машины, грузовики, мотоциклы; $400 за лид за два месяца); цена лида в Google Ads у PI $300–600+, в LSA $85–150 (диапазоны агентств).
- Чистого независимого бенчмарка именно для посадочной по ДТП ни в одном источнике нет.

## Вывод

3% — нижний край: ниже типичных 5–8% для посадочной под платный трафик и ниже 5,45% по категории PI у WordStream, но около среднего по всему трафику сайтов юристов (2,8–3,2%). Это не аварийный уровень, а «ниже ожидаемого для отдельной посадочной».

Связь с ценой лида: цена заявки = цена клика ÷ конверсия. При клике $28: 3% → около $930, 5,45% → около $510, 7% → $400. План $400 при клике $28 требует 7%, при 5,45% нужен клик около $22.

## Ограничения

- Что считать конверсией (звонок, форма, клик по номеру) в источниках разное.
- Для Landver вывод по своей конверсии нельзя делать, пока нет данных: 0 заявок на ~34 кликах (06–18.10.2026), см. [[../Клиенты/Andverpersonalinjury/Хроника_2026-10]].
