# Минус-слова в PMax по отчёту запросов: методика

## Откуда брать
Интерфейс: Campaigns → Insights and reports → Search terms and landing pages for Performance Max (с конверсиями, кликами, показами; минус-слова можно добавлять прямо из отчёта; [справка](https://support.google.com/google-ads/answer/16327396?hl=en-GB)). Через API у ProfiMet есть только категории запросов `campaign_search_term_insight` (30 дней).

## Ловушки выгрузки
1. В конце файла итоговые строки **«Total: Search terms»**, **«Total: Other search terms»** (скрытые малообъёмные запросы), **«Total: Campaign»**. Их нужно исключать из анализа слов, иначе слова «total», «campaign», «other» искажают базу.
2. Разность «Total: Campaign» минус «Total: Search terms» минус «Total: Other» показывает расход на остальные каналы (YouTube, Discover): см. [[../Инструменты/Performance-Max-площадки-инвентарь-и-исключения]].
3. В отчёте обычно нет колонки кампании; сверять итог с расходом нужной кампании.

## Правило значимости перед минусом
1. База = конверсий / кликов по именованным запросам (ProfiMet: 3.0%).
2. Для слова или запроса с n кликами и нулём конверсий вероятность получить нуль случайно = (1 − база)^n. При базе 3%: 25 кликов → 47%, 50 → 22%, 100 → 5%. **Минусовать по данным можно, когда вероятность ниже ~5% (≈100 кликов без конверсий при такой базе).** Меньшие выборки — только по смыслу (явно нецелевой запрос).
3. Считать по словам (корень), а не только по целым запросам; одно слово в формах `ogrodowa` (4 конверсии) и `ogrodowe` (0) — признак шума.
4. Не минусовать общие запросы, пока в целом они конвертируются (ProfiMet: `szklarnia`, `szklarnie ogrodowe` и т. п. — 126 кликов, 4 конверсии).
5. Порядок: смысловой мусор (нецелевое намерение) → значимые нули → остальное под наблюдение.

## ProfiMet, 2026-10-08
Значимых кандидатов нет; запросы с размерами (3x6, 3x4) конвертируются лучше (CPA 17.3 € против 28.8 €). Лог: [[../../Клиенты/ProfiMet/Кампании/РСЯ_КМС/pmax1_test]].
