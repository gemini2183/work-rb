# П-049: у `search / montaz` учтён «Клик по номеру» при выключенной цели OUTBOUND_CLICK

**Симптом:** 16.11 у кампании `search / montaz` (id 24458942621) в конверсиях учтён «Клик по номеру», хотя цель OUTBOUND_CLICK на уровне кампании выключена (`10_данные.md`, раздел «Новые проблемы», п. 6).

**Что известно:** в DG-кампании `dg_montaz_warm_lal` (24.11) цели переведены на уровень кампании: OUTBOUND_CLICK выключен, учитываются форма и звонки (И-116).

**Что НЕ установлено:** почему цель на уровне кампании не отключила учёт (уровень CUSTOMER или ручное отслеживание). Не проверено.

**Обход:** при оценке `search / montaz` исключать «клик по номеру» из заявок; сверять с Ringostat + Supabase.
