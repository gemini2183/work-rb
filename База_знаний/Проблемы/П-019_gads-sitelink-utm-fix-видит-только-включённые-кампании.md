# П-019. gads_sitelink_utm_fix.py не видит ссылки кампаний на паузе и правит все включённые

**Статус:** решена  |  **Система:** Скрипты

## Симптом
Landver Ped+Bike 11.11: новые быстрые ссылки основной кампании (PAUSED) скрипт не находил («у включённых кампаний: 12; без меток: 6» — все 6 из испанской кампании). Запуск с `--execute` тронул бы ссылки испанской кампании, не относящиеся к задаче.

## Причина
Запрос фильтровал `campaign.status = 'ENABLED'` и не умел ограничиваться одной кампанией.

## Решение
В скрипт добавлены `--campaign "<точное имя>"` (любой статус, метки берутся из шаблона этой кампании; остановка, если шаблон не вида `{lpurl}?utm_…`) и `--url-contains <кусок адреса>`; остановка до записи, если ассет привязан ещё к другой кампании (правка на месте изменила бы и её). Без флагов поведение прежнее. Применено 11.11: 6 ссылок, чтение обратно 6 OK, расхождений 0 (И-142).

```
python gads_sitelink_utm_fix.py --customer-id 213-621-6123 --client-folder Andverpersonalinjury --campaign "<имя>" --url-contains <кусок адреса> [--execute]
```

## Как проверить
Без `--execute`: в списке ровно ссылки нужной страницы, чужих привязок нет; после записи «Расхождений: 0».

## Использовано
2026-11-11 Landver Ped+Bike (И-142).

Похожее ограничение: `gads_rsa_text_replace.py` тоже не читает кампании и группы на паузе — при нужде добавить аналогичный фильтр.
