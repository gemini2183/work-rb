# П-050: `gads_demand_gen_builder.py --help` падает на символе «%»

**Симптом:** `python gads_demand_gen_builder.py --help` падает: `ValueError: unsupported format character '?'`. Причина - строка помощи с «2.5%» в argparse (процент не экранирован).

**Что известно:** на запуск без `--help` не влияет (проверено 24.11 11:24–11:26, `--customer-id ... --lookalike-list-id ...` без записи).

**Что НЕ установлено:** есть ли такая же строка в других сборщиках (не проверял).

**Обход:** не вызывать `--help`; читать параметры из кода или `Скрипты/README.md`.

**Исправление (план):** экранировать `%` в строке помощи (`%%`). Не сделано, правка скрипта только по согласованию.
