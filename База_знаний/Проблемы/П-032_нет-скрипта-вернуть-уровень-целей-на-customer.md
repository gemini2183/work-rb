# П-032: нет скрипта, который вернёт уровень целей кампании на CUSTOMER

**Тип:** пробел в скриптах (Google Ads), найден при записи целей `yt_cold` (ProfiMet YouTube, id 24468615055) 13.11.2026.

**Симптом.** Скрипт `Скрипты/gads_set_campaign_goals.py` переводит уровень целей кампании с CUSTOMER (цели аккаунта) на CAMPAIGN (свои цели) с флагом `--execute`. Обратного режима (CAMPAIGN → CUSTOMER) в скрипте нет: в нём только переход на CAMPAIGN.

**Что известно.** В записи 13.11 14:33 уровень `yt_cold` переведён CUSTOMER → CAMPAIGN (Журнал Ю-009, `Работы/2026-11-12_yt_cold/41_запись_цели.md`). Откат значений четырёх целей скриптом возможен по снимку «до» (`файлы\gads_campaign_goals_before_24468615055_20261113_1433.csv`), откат самого уровня скриптом - нет.

**Что НЕ установлено.** Есть ли в интерфейсе Google Ads настройка «использовать цели аккаунта» у кампании и приводит ли она к тем же значениям целей (не проверено). Какие стартовые значения даст Google при возврате на CUSTOMER (не проверено).

**Обход.** Пока кампания на паузе и показов нет, откат значений целей по снимку достаточен. Уровень - вручную в интерфейсе (после проверки) или новым скриптом.

**Решение.** Не принято. Нужен скрипт-вариант с `--customer-level` (или отдельная команда) через `script-builder`, с `validate_only` по умолчанию и чтением обратно. До этого: откат уровня - только по отдельному «да».

**Как проверить.** Запуск нового скрипта без `--execute` на `yt_cold` даёт план; с `--execute` - уровень CUSTOMER и значения целей прочитаны обратно из кабинета.
