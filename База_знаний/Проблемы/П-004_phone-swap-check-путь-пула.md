# П-004. phone_swap_check.py: «Файл пула не найден» или «нечего проверять» при указании --pool-file

**Статус:** решена  |  **Система:** Скрипты

## Симптом (дословно)
С путём вида `../Клиенты/…/Пул….yaml` — «Файл пула не найден» (путь склеивается с папкой клиента); с абсолютным путём — «Нет ни default, ни каналов с непустым пулом».

## Причина
Путь пула читается относительно `Клиенты/<клиент>/`.

## Решение / обход
Передавать `--pool-file "Коллтрекинг/Пул_номеров_<страница>_tilda.yaml"` (как в docstring скрипта).

## Как проверить
Выводятся строки `[OK]`/`[MISMATCH]` по default / Google Ads / ChatGPT.

## Как не допустить
Брать команду из шапки пул-файла.
