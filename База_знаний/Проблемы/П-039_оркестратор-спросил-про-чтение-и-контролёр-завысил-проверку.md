# П-039. Архитектура: три сбоя в прогоне ProfiMet (analyst на gpt-6-luna, orchestrator на Sonnet)

**Статус:** открыта  |  **Система:** orchestrator, controller  |  **Пометка:** архитектура

## Симптом (дословно из прогона, папка `Клиенты/ProfiMet/Работы/2026-11-19_срезы_poliweglan_12-18/`)
1. Оркестратор в конце ответа: «скажите, показать ли срезы с наибольшим расходом отдельной таблицей из 20_данные.md. Это чтение готового файла, без пересчёта».
2. Контролёр в `40_проверка.md`: «Не проверено: ничего», при том что в `30_вердикт.md`: «Не проверено: соответствие заданного окна точке слома данных и независимая сверка атрибуции заявок с CRM».
3. Оркестратор: «Заявки по Ringostat (Supabase `call_view`) 4»; по выводу скрипта 4 = сайт Ringostat 2 + звонки из объявлений 2 + формы Supabase 0.
4. Вывод оркестратора не сообщил, что 17–18.11 расход 49,52 и 44,62 € при 10–14 € в остальные дни (около 65% расхода недели); скрипт вывел это в таблице «потеря показов по дням».

## Причина
1. Правило есть и нарушено: `orchestrator.md`, п. 3: «Вопрос «запускать ли?» не задавай никогда: чтение и запись в вики идут без вопроса. Вопрос владельцу только про запись во внешние системы или выбор, меняющий результат». Показ готового файла в формулировку «выбор, меняющий результат» не подходит, но правило про него молчит.
2. `controller.md`, п. 5: «В конце «Не проверено: …»» не говорит, что туда переносится «не проверено» из вердикта аналитика.
3. Нет правила, что подпись источника копируется дословно из вывода скрипта.
4. `Конституция.md`, раздел 7: «цифры с источниками; доводы только из данных» не требует перечислить заметные отклонения по дням.

## Решение / обход
Внесено 2026-11-19 по решению владельца («ты архитектор», все четыре правки); проверка новым прогоном ещё не сделана:
- orchestrator, п. 3: «Показ готового файла из папки задачи и любое чтение не спрашивай, показывай сразу».
- controller, п. 5: «В «Не проверено» включи все пункты «Не проверено» из 30_вердикт.md и ничего не пропускай».
- Контракт_ответа: подписи источников копируй дословно из вывода скрипта.
- Конституция, раздел 7: добавить «заметные отклонения по дням из данных».

## Как проверить
Новый прогон: оркестратор не задаёт вопросов про чтение; `40_проверка.md` содержит все «Не проверено» из вердикта; подписи источников совпадают с выводом скрипта.
