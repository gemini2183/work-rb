# П-014. tilda.ws отвечает «410 Gone, request automatically blocked» на наши запросы

**Симптом (10.11, после ~20 заходов за вечер):** все адреса `landverpersonalinjury.tilda.ws/...` отдают 410 и текст «Your request has been automatically blocked by our system. If you believe this is an error, you can request an unblock» — и из Python/curl, и из Chrome-расширения (тот же IP).

**Что известно:** до блока подряд шли 6 прогонов `page_tracking_check.py`, три захода в браузере, ~10 скачиваний HTML, плюс клики по форме; блок защитный (WAF Tilda), для обычных посетителей с других IP не обязательно действует.

**Что НЕ установлено:** на какой срок блок; действует ли он на посетителей рекламы (почти наверняка нет — это блок по IP).

**Обход:** не обходить через VPN/прокси; подождать и повторить ОДИН запрос; если не снимется — «Request an unblock» на самой странице блока (форма, по «да» пользователя) или team@tilda.cc.

**Как не повторять:** проверки страниц Tilda делать пакетом (один прогон на страницу), без перезапусков и без скачивания HTML повторно; уже сохранённые отчёты `Статистика/page_tracking_check_*` читать из файлов.
