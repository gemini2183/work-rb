# П-006. На новой странице номер не подменяется: правила Ringostat привязаны к классам элементов

**Статус:** решена (11.11)  |  **Система:** Ringostat

## Симптом (дословно)
Испанская `abogado-accidentes-auto-lawyer-california` (10.11 17:18): 8 ссылок `tel:` все с (844) 452-9465 при метках Google и ChatGPT, `phone_swap_check` 4 из 6 не прошли (default OK). Классы `vb-a1r__btn`, `vb-a1r__stickycall`, `vb-e5v__btn`, `vb-f6w__btn`, `vb-j1a__btn`, `vb-m4d__btn`, `ldvq-phone` не покрыты правилами.

## Причина
Установлено по механизму (CLAUDE.md): правила Ringostat живут в кабинете как XPath; новая вёрстка = новые элементы без правил. Правила `es_*` не заведены (в Ringostat API для этого нет).

## Решение / обход
Завести правила по `Коллтрекинг/Правила_подмены_abogado_tilda.md` в кабинете Ringostat через браузер, по «да»; потом `phone_swap_check.py` с `Пул_номеров_spanish_tilda.yaml`. Реклама на испанскую не включается до 6 из 6.

**11.11 11:20 — подготовлено, не внесено:** правила `abogado …` (6 + 1 по желанию) и JS для консоли — `Клиенты/Andverpersonalinjury/Коллтрекинг/Правила_подмены_spanish_es.md`. Уточнения к обходу: маски кнопок `t-btnflex` обязаны содержать `<span class="t-btnflex__text">…</span>`; видимый номер в ответе FAQ нужно закрыть отдельным правилом; единственное допустимое остаточное несовпадение — скрытый `vb-b2s__success` (П-008). 

**11.11 11:54 — решено:** правила внесены (И-133, 33 -> 39, «Применить настройки» ~12:00); `phone_swap_check.py`: без меток OK; Google десктоп и ChatGPT десктоп/мобильный — все `tel:` и FAQ на номерах пула; остаток только скрытое окно успеха (П-008). Google мобильный отдал (877) 403-8698, которого нет в `Пул_номеров_spanish_tilda.yaml` (подмена работает, пул-файл неполный; задача про верификацию номера открыта). Ввод: код `esFill(i)` + настоящий клик «Сохранить» (клик кодом Ringostat не принимает) — `Коллтрекинг/Правила_подмены_spanish_es.md`. Не проверено: скриншоты, живой звонок.

## Как проверить
`phone_swap_check.py` — все случаи `[OK]`.

## Как не допустить
Новая страница = сначала правила подмены, потом реклама; в ТЗ исполнителю держать общий класс `ldvq-phone`.
