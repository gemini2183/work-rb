# П-006. На новой странице номер не подменяется: правила Ringostat привязаны к классам элементов

**Статус:** открыта  |  **Система:** Ringostat

## Симптом (дословно)
Испанская `abogado-accidentes-auto-lawyer-california` (10.11 17:18): 8 ссылок `tel:` все с (844) 452-9465 при метках Google и ChatGPT, `phone_swap_check` 4 из 6 не прошли (default OK). Классы `vb-a1r__btn`, `vb-a1r__stickycall`, `vb-e5v__btn`, `vb-f6w__btn`, `vb-j1a__btn`, `vb-m4d__btn`, `ldvq-phone` не покрыты правилами.

## Причина
Установлено по механизму (CLAUDE.md): правила Ringostat живут в кабинете как XPath; новая вёрстка = новые элементы без правил. Правила `es_*` не заведены (в Ringostat API для этого нет).

## Решение / обход
Завести правила по `Коллтрекинг/Правила_подмены_abogado_tilda.md` в кабинете Ringostat через браузер, по «да»; потом `phone_swap_check.py` с `Пул_номеров_spanish_tilda.yaml`. Реклама на испанскую не включается до 6 из 6.

## Как проверить
`phone_swap_check.py` — все случаи `[OK]`.

## Как не допустить
Новая страница = сначала правила подмены, потом реклама; в ТЗ исполнителю держать общий класс `ldvq-phone`.
