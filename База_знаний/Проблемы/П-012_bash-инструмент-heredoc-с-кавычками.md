# П-012. Инструмент Bash: многострочный heredoc с апострофами/«кавычками» падает (`unexpected EOF`)

**Статус:** решена  |  **Система:** Окружение

## Симптом (дословно)
`bash: -c: line N: unexpected EOF while looking for matching `''`, ничего не выполнено.

## Причина
Разбор длинной многострочной команды.

## Решение / обход
Длинный текст сохранять через Write в файл в scratchpad и дописывать скриптом (`append_*.md` → `open(...,'a')`), не heredoc'ом.

## Как проверить
Файл дописан, число строк выросло.

## Как не допустить
Не слать длинные тексты heredoc'ом.
