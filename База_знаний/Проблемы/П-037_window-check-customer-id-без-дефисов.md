# П-037: в Скрипты/README.md не указано, что window_check.py принимает customer-id без дефисов

**Тип:** документация скрипта.

**Симптом.** При разборе 17.11 `window_check.py` запускали с id без дефисов (`2136216123`, аккаунт Landver `213-621-6123`). Что будет с дефисами, не проверено. Указания в `Скрипты/README.md` на этот формат в ходе 17.11 не проверяли (файл не читали), поэтому утверждать «README молчит» пока нельзя.

**Что известно.** Работает с id без дефисов: `Клиенты\Andverpersonalinjury\Работы\2026-11-17_landver_top_impr\20_эффект.md` (шапка, источники).

**Что НЕ установлено.** Есть ли в README указание на формат id. Падает ли скрипт с дефисами или тихо отдаёт пустой результат.

**Обход.** Передавать id без дефисов.

**Решение.** Не принято. Варианты: строка в README либо приём дефисов в скрипте (решает владелец скриптов).

**Как проверить.** `Grep` по `Скрипты/README.md` на `customer-id` и `дефис`. Затем запуск с обоими вариантами id по одному дню, только чтение, из папки `Скрипты/` (см. П-025).
