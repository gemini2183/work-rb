# П-045: нет read-only чтения меток «Customer Type» на списках аудиторий (Google Ads)

**Симптом (дословно из работы):** «Нет read-only режима для меток «Customer Type». Сейчас единственный способ прочитать метки - запуск `gads_remove_customer_type_labels.py --ids 0` (пишущий скрипт; при `--ids 0` до мутации не доходит, но это обход).»

**Что известно:** метки «Purchasers» на списках ProfiMet снимались скриптом в 10.2026 (И-006). Чтение меток без записи в скрипте нет.

**Что НЕ установлено:** нет ли в API способа прочитать метку без пишущего скрипта (проверка не делалась).

**Обход:** не использовать `gads_remove_customer_type_labels.py` для чтения. Нужен скрипт чтения списков: id, имя, тип, размер Display/Search, срок, метка.

**Найдено:** 24.11.2026, `Клиенты\ProfiMet\Работы\2026-11-24_dg_montaz\10_данные.md`, раздел «Новые проблемы», п. 1.
