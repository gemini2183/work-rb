# П-029: подпись плана в `state_digest.py` для ProfiMet

- **Симптом (дословно, 13.11):** «план месяца (Ноябрь 26 …): бюджет 6000, заявок 200, цена заявки 30» и «нужная цена заявки на остаток = (6000 - 845) / 143.0 = 36 (план 30)», где 143 = 200 − 57 заявок.
- **Причина:** 200 — продажи, 30 € — цена продажи (`Клиенты/ProfiMet/Цели/goals.md`, запись 03.11). Скрипт вычитает из продаж плана количество заявок (57) — разные единицы, вывод «36 против 30» не имеет смысла.
- **Что НЕ установлено:** есть ли у других клиентов таблицы с продажами вместо заявок.
- **Обход:** для ProfiMet раздел [4] читать только по расходу и темпу; цену продажи считать `profimet_price_per_sale_by_campaign.py`.
- **Идея решения:** признак «план в продажах» в `analysis_config.yaml` (секция `plan`) и расчёт по продажам. Правка — через `script-builder`.
- **Как проверить:** в разделе [4] ProfiMet нет сравнения продаж с заявками.
