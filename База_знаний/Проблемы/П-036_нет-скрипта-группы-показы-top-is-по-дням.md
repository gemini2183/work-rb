# П-036: нет скрипта показов, Top IS, CTR и цены клика по группам объявлений по дням

**Тип:** пробел в скриптах (Google Ads, разрез по группам объявлений).

**Симптом.** Нет скрипта, который выдаёт по дням и по группам кампании 24331208797 показы, долю показов вверху (Top IS), CTR и цену клика. `search_term_view` (через `gads_campaigns_breakdown.py --search-terms`) видит только часть показов: охват за 10–17.11 — 63,8% показов, за 17.11 — около 53%. Доля вверху по группам не получена.

**Что известно.** По видимым запросам, 17.11 против 5 дней до правки (с показами): Bicycle 108 против 51, Motorcycle 110 против 95, Pedestrian 67 против 136. Источник: `Клиенты\Andverpersonalinjury\Работы\2026-11-17_landver_top_impr\20_эффект.md` и `31_запросы_вывод.md`.

**Что НЕ установлено.** Доля вверху и цена клика по каждой группе. Причина роста Bicycle и падения Pedestrian (причину не назначали).

**Обход.** Видимые запросы по группам с оговоркой про охват; показы по группам считать «видимыми», не полными.

**Решение.** Не принято. Нужен скрипт только на чтение (агент `script-builder`): группы × дни, показы, Top IS, CTR, цена клика.

**Как проверить.** Сумма показов по группам за день сходится с показами кампании за тот же день по `gads_impression_share.py`; расхождение объясняется сроком среза.

**Связано:** `20_эффект.md`, `31_запросы_вывод.md` (17.11).
