# П-026: агенты проекта (`campaign-scout`, `fact-checker` и др.) не найдены в сессии

**Симптом (дословно):** `Agent type 'campaign-scout' not found. Available agents: claude, claude-code-guide, Explore, general-purpose, gtm-checker, Plan, statusline-setup` (12.11, VS Code-расширение, сессия ProfiMet YouTube `yt_cold`). Файлы `.claude/agents/*.md` в репозитории есть и изменены (git status M), но список доступных типов их не содержит.

**Не установлено:** почему не загрузились (сессия стартовала до правок файлов, формат frontmatter, расширение VS Code читает агентов иначе).

**Обход:** `general-purpose` + в задании «сначала прочитай плейбук `.claude/agents/<имя>.md` и следуй ему». Хук чтения (`agent_read_guard`) при этом не действует (см. [[П-021_хук-чтения-агентов-не-проверен-агент-отказывается-по-инструкции|П-021]]): запрет «не читать» держится только на тексте задания. Сработало для разведчика, контролёра фактов, планировщика (12.11), результаты по контракту.

**Повтор 13.11 (сессия оптимизации лимита, VS Code):** та же ошибка для `status-reader` и `fact-checker`; список типов тот же (из проектных виден только `gtm-checker`). Сессия стартовала после последних правок файлов агентов, так что версия «сессия старше правок» не подтверждена. Frontmatter у `gtm-checker` и `fact-checker` устроен одинаково (tools, model, hooks), почему виден только один - не установлено. Обход использован в замере haiku/sonnet (`general-purpose` + «прочитай плейбук»); хук чтения в замере не действовал.

**Вероятная причина (найдена 13.11, не проверена в харнесе):** `yaml.safe_load` frontmatter 12 из 13 файлов `.claude/agents/*.md` падает с `mapping values are not allowed here` - в `description` без кавычек есть `: ` (например «…по направлению, клиенту или всем клиентам: запускает…»). Единственный файл, который разбирается (`gtm-checker.md`), - единственный проектный агент, видимый в списке. Совпадение 13/13 по двум признакам. Решение-кандидат: взять `description` в кавычки (или переписать без `: `) во всех 12 файлах, открыть новую сессию, проверить список типов. **Сделано 13.11 по «да»:** `description` взят в одинарные кавычки во всех 13 файлах, `yaml.safe_load` проходит у всех 13. Проверить в новой сессии: типы `status-reader`, `fact-checker` в списке `Agent`. Откат: `git checkout -- .claude/agents`.

**Подтверждено 13.11 в той же сессии:** после правки харнес сам обновил список, в `Agent` появились все 12 проектных типов (`ad-copywriter`, `campaign-*`, `fact-checker`, `gtm-executor`, `image-creator`, `page-check`, `problem-solver`, `script-builder`, `status-reader`, `wiki-recorder`); перезапуск сессии не понадобился. Правило на будущее: после правки frontmatter агента проверять `yaml.safe_load`; `description` с `: ` - только в кавычках. Хук чтения (`agent_read_guard`) на настоящих типах ещё не проверен - П-021.

**Как проверить решение (выполнено):** новая сессия, в списке типов Agent появляются `campaign-scout`, `fact-checker`.
