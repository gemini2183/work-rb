# П-048: размеры аудиторий меняются между выгрузками без объяснения

**Симптом:** `user_engagement (30 дн.)` размер 1 900 → 180; look-alike 2,5 % 540 000 → 2 100 000. Изменения без объяснения (24.11, ProfiMet).

**Что известно:** размеры из разных выгрузок (`gads_audiences_audit.py`, интерфейс Ads, Display/Search) не совпадают. Размер look-alike 2,5 % больше размера 5 % (по смыслу 5 % включает 2,5 %), объяснения нет.

**Что НЕ установлено:** причина (тип оценки, разрез по сети, обновление списка). Не проверено.

**Обход:** размеры аудиторий в границах гео брать из интерфейса Audience manager и помечать источник; не использовать одну выгрузку как факт.
