# П-024: оценка по группам при приостановленной кампании

- **Симптом:** решение 10.11 «Rideshare остаётся, потолок $200, оценка 17.11» принято при группе active, но кампания «topics» была paused с 06.11 09:52 (Варшава, `pause_context.paused_at`); показов с 07.11 нет, расход стоял на $113.
- **Причина:** `openai_ads.py groups` печатал только статус групп; статус кампании в сводках не проверяли. Кто поставил паузу, API не показывает.
- **Решение:** `groups` теперь первой строкой печатает статус кампании и время паузы (`КАМПАНИЯ … paused (paused_at … UTC)`). Правило: перед назначением срока оценки по OpenAI Ads читать статус кампании и посуточные показы (`insights --granularity daily`), а не только группы.
- **Как проверить:** `python Скрипты/openai_ads.py groups --campaign <id>` — первая строка со статусом кампании.
- Связано: И-148, И-150, Э-15.
