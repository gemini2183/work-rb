# Семантика — Корогва

Источники: [[../../Скрипты/gads_semantics_korogva|Скрипты/gads_semantics_korogva.py]]
(ключи `keyword_view` по не-Merchant кампаниям + поисковые запросы `search_term_view`
по всем кампаниям), окно 60 дней (2026-05-28 → 2026-07-26), конверсии учтены
только с 2026-07-09 (см. [[../Цели/goals|Цели/goals]]).

## 1. Состояние загруженных ключей (Search-кампании)

Всего загружено **1328 ключей** (ENABLED: 1093, PAUSED: 235) в трёх кампаниях:
"Пошук \ Бренд" (9), "Пошук \ Прапори" (527), "Пошук \ Одяг" (792).

**92% ключей (1227 из 1328) не получили ни одного показа за 60 дней**,
включая 1006 из 1093 ENABLED. Это не случайность — примеры показывают
пакетно сгенерированные гипер-длинные фразы (база + модификатор), явно из
инструмента массовой генерации семантики: `флаг дронщика`, `флаг минометчиков`,
`флаг связистов`, `свитшот армійські вартість`, `свитшот мілітарі замовити`.
Похоже на статус "низкий объём поиска" в Google Ads — ключи формально в
кампании, но система их никогда не показывает. Из ~100 ключей, получивших
показы: 29 — с показами, но 0 кликов; 68 — с кликами, но 0 конверсий
(в окне с 9 июля).

**Статус:** требует решения пользователя — чистить ли аккаунт от мёртвых
ключей (задача заведена в [[../Задачи|Задачи]]), это не блокирует анализ
семантики, но раздувает интерфейс и может размывать статистику по группам.

Кампания `Merchant_Performance Max-1` не отдаёт поисковые запросы через API

Все данные ниже — из `Merchant_Shopping` (обычный Shopping, 13848 уникальных

## 3. Разбор "мерч"-трафика — НЕ используется

489 уникальных запросов содержат "мерч"/"merch", но это почти целиком поиск
официального мерча ДРУГИХ артистов/групп/блогеров (метал-группы, украинские
музыканты и общественные деятели — Стерненко, Русоріз, Норд Дивижн, Мур и
десятки других). Не пересекается с ассортиментом Корогвы — если нет реальных
коллабораций с кем-то из списка (не подтверждено), этот трафик игнорируется.
Генерик-запросы категории ("мерч", "військовий мерч", "мілітарі мерч",
"патріотичний мерч") — минимальный объём, отдельно не выделялись как приоритет.

## 4. Кандидаты на расширение семантики (gap-анализ)

Метод: поисковые запросы из Merchant/Shopping, релевантные ассортименту (по
факту реальных названий товаров, см. [[../_project|_project]]), которых нет
среди загруженных ключей. Официальные/гос. флаги (ЗСУ вообще, Донецкая область
как административный регион) — **отклонены пользователем 2026-07-27**, не
входят в ассортимент.

Сведено по темам × типам товара (сумма показов/кликов по всем словоформам —
не отдельные ключи, а обоснование для фразового ключа-"зерна"):

| Оверсайз (форм-фактор) | худі | 725 | 12 | 1.7% |

**Важно:** конверсий (custom_purchase, с 9 июля) по всем этим темам — **0**.
Это анализ доказанного интереса (показы/клики за 60 дней), не доказанной
конверсии — обоснование для расширения охвата, не гарантия продаж. "Прапор
вампір" (CTR 11.4%) — самый заметный сигнал, но это 9 кликов на 79 показов,
статистически ничтожная выборка, нельзя делать выводов сильнее, чем
"выглядит многообещающе, требует проверки на большем объёме после добавления".

### Рекомендуемые фразы-кандидаты (по группам, для добавления как PHRASE-ключи)

Не добавлять built-in-длинный список из 669 сырых вариантов запросов — это
повторило бы проблему п.1 (раздутая псевдо-семантика). Вместо этого — по
одному-два зерна на тему×товар, фразовое соответствие само покроет вариации
словоформ/порядка слов:

- **Мілітарі/військова** (кампания "Пошук \ Прапори", группа "Милитари — RU"
  уже существует, но её текущие ключи не работают — заменить содержимое, не
  саму группу): `прапор мілітарі`, `прапор військовий`, `футболка мілітарі`,
  `футболка військова`, `худі мілітарі`
- **Оверсайз** (новая группа в "Пошук \ Одяг" — форм-фактор, не тема дизайна):
  `худі оверсайз`, `футболка оверсайз`, `штани оверсайз`, `зіп худі оверсайз`
- **Вампір/дрон/фпв** (прямое совпадение с товарами "Вампір", "ФПВ", "Дрони
  ведуть"): `футболка вампір дрон`, `футболка фпв`, `прапор вампір`
- **Донбас/Донецьк** (совпадает с товаром "Донецьк" — не гос-флаг региона):
  `футболка донбас`, `прапор донбас`
- **Череп/skull** (совпадает с "Худі Skull"): `футболка з черепом`, `худі з
  черепом`

### Отклонено пользователем (не ассортимент)

- Флаги ЗСУ в общем виде (`прапори зсу`, `флаги зсу`) — не тема дизайна
- Флаг/герб Донецкой области как административного региона (`флаг донецкой
  области`, `донецька область шеврон`) — не тот же смысл, что тематическая
  футболка "Донецьк"
