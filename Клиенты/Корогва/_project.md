# Корогва — бриф проекта

## Ниша / продукт

Украинский бренд одежды и флагов (corogva.com), e-commerce. **Уточнено
2026-07-27 по реальным фото каталога** (не просто "патриотика/юмор" — это был
слишком общий первый заход по описанию с сайта): фирменный дизайн — авторский
тёмный мілітарі-арт с маскот-персонажем (скелет в противогазе/балаклаве),
военная/дроновая тематика конкретных сюжетов, не общая символика. Конкретные
названия товаров (для ориентира при подборе семантики/креативов):
- Флаги: "Грім і сталь", "Перехоплювач", "Втрата сигналу", "Baby Shark",
  "Вампір", "Знайомство з пісюном", "Спіймані чмоні", "Стабік" (~1650 ₴)
- Футболки: "Дрони ведуть", "Welcome to hell", "Війна триває", "Морпіхи",
  "Очі темряви", "Донецьк", "ФПВ", "Воїн в полі"
- Худі oversize: "Війна триває", "Історія", "Skull"

Каталог по типам: Флаги (коллекции 1.0–4.0, государственные, декоративные),
одежда мужская/женская (футболки, лонгсливи, світшоти, худі/зіп-худі, шорти,
штани), разделы Новинки/Sale.

Аудитория — молодёжь и взрослые украинцы, интересующиеся военной/дрон-тематикой
в мрачном авторском стиле — уже, чем просто "любители украинской символики".
Это объясняет разбивку аккаунта на два подпроекта (см. ниже): "Merchant Center"
— товарные объявления по фиду каталога (Shopping/PMax по товарам), "Google Ads"
— Search-кампании по брендовым и тематическим запросам.

## Технический контекст

Агентство Adwhite (Google Ads), не Redbird (Директ) — отдельная общая таблица
клиентов (см. [[../../Инфраструктура|Инфраструктура]]). Один аккаунт Google Ads
(client_id 845-234-6433, MCC login_customer_id 3023486398), разбитый на два
подпроекта по названию кампании, не по отдельному customer_id:
- "Корогва - Google Ads" — обычные кампании
- "Корогва - Merchant Center" — товарные кампании (название содержит "Sales"
  или "Merchant_")

Раньше конверсии собирались отдельно из GA4, трафик — из Google Ads API
(старая схема Adwhite). Сейчас переведено на единый источник — Google Ads API
целиком (трафик + конверсии одним запросом), GA4 не используется. См.
[[../../Скрипты/README|Скрипты/README]] и [[Решения]].
