# EkspertAgro — Мерчант — индекс

Подпроект: только кампании, связанные с Merchant Center и работающие по
товарному фиду. Общий Google Ads аккаунт — тот же, что у [[../Теплицы_Польша/index|Теплицы_Польша]],
см. общий [[../index|индекс EkspertAgro]].

Текущий статус одной строкой: Merchant Center фид актуализирован
(153 товара, язык "Польский", скрипт `merchant_feed_ekspertagro.py` для
пересборки с сайта); PMax feed-only (`shop_pmax`) запущена и работает с
2026-09-22 — первая проверка распределения показов по сетям сделана
(см. [[Решения]], запись 2026-09-24), следующая контрольная точка
~2026-10-05/06, см. [[Задачи]]. Помимо `shop_pmax`, в аккаунте есть три
Shopping-кампании в Поиске: `shop_search` (ENABLED, с 2026-09-02) и две
PAUSED (`shop1 /search`, `shop2 / search`, работали 2025-12-08 → 2026-05-26)
— годовой анализ поисковых запросов и рабочих размеров теплиц/тоннелей
сделан 2026-09-24, см. [[Решения]].

**2026-09-28:** `shop_search` разбита пользователем на 4 размерные Ad Group
(`3x4`, `3x6`, `2x4`, `4x6`) + `all products` — намеренно сужен таргетинг
на ~19 конкретных товаров, остальной каталог явно исключён ("Everything
else... Excluded" во всех группах, статус кампании "Not eligible" — это
ожидаемое поведение при такой настройке, не баг, подтверждено скриншотом).
Написан регулярный инструмент `Скрипты/gads_shopping_size_negatives_by_group.py`
— по каждой размерной группе находит запросы на размеры вне фида и сразу
готовит минус-фразы, хранит дату последнего запуска сам. Контрольная точка
следующего регулярного прогона — 2026-10-12, см. [[Задачи]].
