### Заготовка для новой сессии: клик по номеру на EA
**Зачем.** У EA PMax работает только на статических номерах Ringostat: звонок приходит без gclid, `client_id` звонка не равен cookie `rngst` посетителя (тест с телефона на ProfiMet 12.11: визит `5742e23b…`, звонок `6c7a960b…`), в карточке звонка и API идентификатора нет. Связка «последний визит той же кампании до звонка» на потоке PMax ProfiMet верна лишь в ~25% (замер 12.11). Идея пользователя: на телефоне люди нажимают номер (у PMax 99% визитов мобильные, у YouTube 88%), звонок приходит через секунды после нажатия — записывать сами нажатия (время, `rngst`, gclid, кампания) и сопоставлять звонок с нажатием по окну в секунды. Клик по номеру при этом НЕ конверсия: в Ads грузим только пару «звонок ↔ найденный клик». Скрывать номер на десктопе и ставить форму обратного звонка не нужно (десктоп у PMax ~1%).
**Не измерено (мерить в первую очередь):** (1) через сколько секунд после нажатия звонок появляется в Ringostat; (2) как часто в одну минуту нажимают несколько человек (тогда пара неоднозначна); (3) сколько звонков в неделю приходит на статические пулы PMax EA (по октябрю — единицы: `Google CPC General - pm` 7, `shop_pmax` 7 первых звонков за период; если поток единицы, вывод через две недели может быть «данных нет»); (4) стоит ли на `ekspertagro.pl` вообще скрипт Ringostat с подменой, есть ли там статические пулы под PMax и кто принимает звонки (все входящие EA идут переадресацией на `48579774289`, см. задачи выше); (5) есть ли в GTM `GTM-5FBCZLMC` уже тег «клик по номеру» (в Ads у EA есть конверсия «Клик по номеру»).
**Что известно про EA для работы:** сайт `https://ekspertagro.pl/` (Tilda); GTM `GTM-5FBCZLMC` (аккаунт `6326663960`, контейнер `236673117`; живая версия на 19.10 — 20; правки по образцу `Скрипты/gtm_ekspertagro_supabase_fix.py`); Google Ads `882-613-4558`; Supabase: таблица `expertagro_leads` уже есть; PMax: `shop_pmax` (активна), `general_pmax_rozmiary` (пауза с 10.11, Э-022); Ringostat-проект EA — искать по `ea_ringostat_vs_sheet.py`/`ringostat_ekspertagro`; звонки EA в Ringostat ProfiMet (`n_alias` `48579774289`) не путать с проектом EA.
