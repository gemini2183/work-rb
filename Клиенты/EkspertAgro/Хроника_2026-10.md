## 14.10 (позже) — какие формы Tilda приняли спам из `general_pmax`
- **Источник данных:** выгрузка Tilda «ea-tilda forms.xlsx» (40 заявок 01–14.10; есть телефон, ID формы, страница с UTM) + статусы «Заказ отменён» из Ringostat (скриншот, 16 видимых строк); сопоставление по телефону — совпали все 16. Время в Tilda на 1 час позже Ringostat. Что за блок стоит за ID формы — по HTML главной и `/szklarni` на 14.10 (редактор Tilda не открывали).
- **Измерено:** в `general_pmax` с 05.10 — 17 форм Tilda (совпадает с 17 строками Supabase). 16 из них — «Заказ отменён»: 15 с тегами «номер фейк / не верный номер / нет такого номера / автоответчик» и одна живая (09.10, +48606389519: «ответил, что уже заказал»). 17-я (08.10 10:14, +48602392446) на видимой части скриншота не отображается — статус не известен.
- **Все 17 пришли в две формы, обе — всплывающие окна на главной с одним полем «Телефон»:** `form1500911531` — «Zamów szklarnię online» (кнопка «Zamów szklarnię» на первом экране), 10 из 17; `form1500825761` — «Zamów bezpłatną konsultację» (кнопки «Konsultacja» на первом экране и «Zamów kontakt» в блоке про консультантов), 7 из 17. Страница отправки у всех — главная с `utm_campaign=general_pmax`. Те же формы получили и 6 заявок Facebook, поэтому «формы виноваты» — неверно: виноват трафик, формы лишь принимают любой номер (прошёл даже `+213…`, Алжир).
- **Не из `general_pmax` (для сравнения):** `form1522438571` — корзина/заказ из карточки товара (12 заявок: Facebook 3, прочее 9), все с именем и адресом; `form1693698681`, `form1693702971`, `form2024417253` — опросник-квиз (на `/szklarni`, `/akcesoria-do-szklarni`, карточке «Tunel Tytan»), `form1495544051` — контактная форма на `/kontakt`. Спама из `general_pmax` в них нет.
- **Признак источника (измерено на 17 строках):** у всех 15 фейков `gad_source=5` и `gad_campaignid=23603804134`, устройство mobile; у двух остальных (08.10 и живая 09.10) `gad_source=1` и другие `gad_campaignid` (23603799757, 23593719735). Всплеск: 05.10 — 1, 10.10 — 6, 12.10 — 3, 13.10 — 3, 14.10 — 2; пары заявок с интервалом 1–3 минуты (13:27/13:28, 13:39/13:41, 09:35/09:38 по Tilda), номера-«узоры» (…5151111, …901470000, …222442232) — похоже на ручной ввод.
- **Не проверено:** какому каналу PMax (медийка, YouTube, Discover…) соответствует `gad_campaignid=23603804134` — гипотеза «это медийная сеть» согласуется с 14.10 (почти весь расход CONTENT), но связь по ID не доказана. Проверка: в кабинете сопоставить время фейков с площадками/каналом за 10–14.10.
- **Дальше:** (а) на Tilda-формы добавить проверку номера (маска только +48, 9 цифр) — снизит мусор, но не источник; (б) при новом запуске PMax пометить в UTM канал, чтобы видеть источник фейков.

## 14.10 — спам-заявки в `general_pmax`, площадки медийной сети, темп месяца
- **Ситуация:** клиент сообщает о спамовых заявках, быстром расходе и почти полном отсутствии звонков; просит поставить `general_pmax` на паузу. Кампания на паузе с 14.10 09:37 (см. Журнал, Э-002). Проект под риском закрытия — нужно быстро наверстать план, но без спама.
- **Измерено (Ads, `gads_pmax_placements.py`, 09–14.10):** почти весь расход — медийная сеть (CONTENT): 10.10 — 553.6 zł, 12.10 — 625.5 zł, 13.10 — 319.4 zł, 14.10 (до паузы) — 227.6 zł. Конверсии Ads в этой сети: 11 / 3 / 4 / 2. Из 11 конверсий 10.10 шесть — «Клик по номеру» (не заявка), пять — форма. Формы в Ads по дням: 2 / 5 / 3 / 3 / 2 (09, 10, 12, 13, 14.10); 11.10 в выгрузке нет строк.
- **Площадки (показы, 61 080 за период, 625 площадок):** taboolanews.com 21.7%, wp.pl 11.8%, onet.pl 11.1%, дальше squidapp.co, o2.pl, lsmagazineimg.com, interia.pl, paul-kaik.ai, apexnews.com, weather.com, fakt.pl и мобильные приложения (виджет погоды, BusNavi, Block Blast). Все пять кандидатов из задачи 12.10 присутствуют. Пик 10.10 — taboolanews.com (6 807 показов), пик 12.10 — польские порталы (onet.pl 4 270, wp.pl 4 086). Расхода и кликов по площадкам API не отдаёт — какая площадка сожгла деньги, не знаем.
- **Темп месяца (1–14.10, расход Ads):** `general_pmax` 2 540 zł из плана «Теплицы Польша» 6 500 (39% бюджета при 45% месяца), 37 конверсий Ads (включая «Клик по номеру», не заявки); остаток 3 960 zł на 17 дней = ~233 zł/день. Мерчант (`shop_search` + `shop_pmax`) 1 250 zł из 4 300 (29%). Число реальных заявок за месяц (Ringostat + Supabase) на этой стадии не сверено.
- **Формы Supabase (`expertagro_leads`, 20.09–14.10, 69 строк):** в таблице только `phone`, UTM и время, **текста заявки и имени нет**; телефон заполнен у 6 из 69, везде 2 цифры («48») — поле по сути не передаётся. Спам по содержимому из Supabase определить нельзя. Без UTM — 29 из 69 (42%).
- **`general_pmax` по дням, формы Supabase:** 05.10 — 1, 08.10 — 1, 09.10 — 1, **10.10 — 6**, 12.10 — 3, 13.10 — 3, 14.10 — 2 (всего 17 с 05.10). Совпадает с формами Ads (2/5/3/3/2) и с началом всплеска в медийной сети 10.10. 10.10 четыре формы за 14 минут (12:27–12:41); утренние формы 12.10 в 08:35 и 08:38, 14.10 в 08:36 и 08:54 — наблюдение, причинная связь не проверена.
- **Не доказано:** что именно форм-спам идёт с медийной сети и с какой группы ассетов; нужны примеры спама от клиента (время + содержимое/телефон из его почты или CRM), чтобы сопоставить по времени со строками Supabase.
- **Решение пользователя 14.10:** площадки вслепую (без данных по расходу и конверсиям площадки) не отключать; исключения не готовим, пока не понятен источник спама.
- **Идеи пользователя (в Задачи/Бэклог):** тест новой конфигурации PMax; проверить affinity/интересы по находкам ProfiMet; тестовый Search на страницы с фильтрами размеров 3x4/3x6.

## 14.10 (позже) — посадочные страницы и идея Search на отфильтрованный каталог
- **Факт (чтение кабинета):** у всех объявлений `final_url` = `https://ekspertagro.pl/` (главная): четыре группы ассетов `general_pmax` и все RSA в `general / search / poliweglan` и `general / search / szklarnia/tunel`. Обе поисковые кампании на паузе (с какой даты — не выяснено). В `general_pmax` включена только группа «Заинтересованные покупатели» (кампания на паузе).
- **Факт (сайт, Playwright):** главная без цен и карточек (опросник из 5 вопросов, ссылка «Katalog»). Каталог `https://ekspertagro.pl/szklarni` — Tilda Store с фильтрами: толщина поликарбоната 4/6 мм, профиль 20x20/40x20, длина, ширина, высота, площадь. Фильтр кодируется в URL и применяется при прямом заходе: ширина 3 м + длина 6 м → 6 карточек (1 949–2 549 zł), 3x4 → 6 карточек (1 599–2 049 zł); + толщина 6 мм → 3 карточки (3x6: 2 549 / 2 449 / 2 179 zł). Ключи фильтров: ширина `tfc_charact:9246142[1500649011]`, длина `tfc_charact:9246152[1500649011]`, толщина `tfc_charact:9456082[1500649011]` — зависят от каталога в Tilda и могут смениться при его правке. Карточка товара: цена, характеристики, кнопка «Zamówienie», телефон.
- **Shopping за год (14.10.2025–14.10.2026, конверсии Ads, не сверены с Ringostat), позиции 3x4/3x6:** 3x6/4 мм 40x20 — 28.8 конв., 134 zł; 3x4/6 мм 40x20 — 23.4 конв., 74 zł; 3x4/4 мм — 9.8 (109 zł); 3x6/6 мм — 9.5 (168 zł); профиль 20x20 даёт заметно меньше (6 мм: 0.1 конв.). Лидер по объёму — 2,5x2 м/4 мм (68.3 конв., 161 zł) — вне идеи про 3x4/3x6.
- **Решения пользователя 14.10:** посадка Search — широкий выбор (каталог с фильтром ширина+длина), дальше человек фильтрует сам; на «6 mm» отдельную карточку не делаем (не уверены, что Google так разнесёт запросы); старые поисковые кампании не переделываем, весь Search собираем заново.
- **Проверка трекинга на страницах каталога и карточки (14.10, Playwright + публичный GTM-5FBCZLMC + скрипты Tilda):**
  - Подмена Ringostat: при `utm_source=google&utm_medium=cpc&utm_campaign=general_pmax` на главной, каталоге с фильтром и карточке (desktop и mobile) везде `+48 172 508 541` (пул PMax), статический номер сайта не показан.
  - GTM-5FBCZLMC и скрипты Ringostat, Метрики, Facebook грузятся на всех трёх типах страниц.
  - Конверсия формы: в контейнере тег срабатывает на событие dataLayer, подходящее под регулярку `submit_form*`, без условий по адресу страницы; это событие `submit_<id формы>` шлёт собственный скрипт Tilda (`tilda-forms-1.0.min.js`), он подключён и на каталоге, и на карточке. «Клик по номеру» — отдельный триггер на любой клик по `tel:`.
  - **Не проверено:** реальная отправка формы заказа («Zamówienie») на карточке — тестовую заявку не отправляли (создала бы конверсию и строку в Supabase). Подтверждение — первая реальная форма после запуска: сверить Ads и Supabase.
  - Побочный вывод: регулярка срабатывает на **любую** форму Tilda (опросник, обратный звонок, заказ) — все они считаются как `form_submit_web`.

Детали и чтение обратно — Журнал, Э-003; план — [[Кампании/Search/search_szklarnia_3x4_3x6]].
- Ожидание: 5–9 заявок в месяц при ~1 200 zł; закрыть разрыв плана (59 заявок по «Теплицы Польша») этот канал не может — нужен второй источник объёма (новая PMax).

- **Как выгрузки делят «Мерчант» и «Теплицы» (проверено по коду 14.10):** `gads_eksperagro` — по слову `shop` в названии кампании, фильтра по ID кампаний в листе `Adwords` нет (поле пустое, загружаются все); `ringostat_ekspertagro` — по `shop`/`merchant` в `utm_campaign`, кампании с `test` в `utm_campaign` отбрасываются. - **Проверка посадочных 14.10 (одним прогоном, после снятия блокировки Tilda):** все 4 группы — фильтр применился, номер из пула General; на 2 из 4 страниц показан статический `+48222565341` (в пуле, звонки неотличимы).
- **Расширение (Э-004):** по вопросу пользователя «почему только два размера» добавлены группы 2x4 и 4x6 (3x6+3x4 — ~75% спроса каталога; 2x4 и 4x6 — следующие с конверсиями на уровне цели, выборка малая). 3x8 и 4x8 не добавлены. Ожидание по кампании в целом: ~1–2 заявки в месяц сверху к прежним 5–9.

## 13.10 — сторож и бренд ProfiMet
- **План месяца (таблица «Цели2 Адвайта», «Октябрь 26»):** «Ekspertagro — Теплицы Польша» 59 заявок / CPA 110 / бюджет 6 500; «Мерчант» 39 / 110 / 4 300; «ФБ» 39 / 110 / 4 300 (Facebook). Соответствие подтверждено пользователем: `general_pmax` → «Теплицы Польша», `shop_search` и `shop_pmax` → «Мерчант».
- **Сторож расхода и цены заявки** запущен 10:58 (универсальный, `--client EkspertAgro`, конфиг [[guard_config.yaml]]): цель 110 zł, допустимый расход (2 + заявки) × 110, только пауза, возобновление и бюджет выключены; заявка = звонок Ringostat + форма Supabase + «Calls from ads» из Ads. - **Ограничение:** 15 из 39 форм за 14 дней в Supabase без метки кампании (38%), контейнер GTM-5FBCZLMC правки UTM не получал.
- **Поправка по ходу (честно):** цель сторожа сначала была 150 zł (KPI из конфига мониторинга), заменена на 110 zł из таблицы плана.
