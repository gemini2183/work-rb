# План тестов ProfiMet (составлен 2026-10-08)

Цель: вернуть проект в план (273 заявки, CPA 22 €; сентябрь: 142 заявки, 30.9 €) за счёт объёма из каналов с лучшей ценой заявки. Принцип: одно окно правок 22.10 (после двух недель покоя `pmax1_test` и `Poliweglan`), параллельные тесты не запускаем, пока не видим результат предыдущего. Все записи в кабинеты — по таблице плана и только после «да».

## Где деньги (факты, 2026-10-08)
- Search внутри PMax: CPA 23 € (01.09–08.10), 68% конверсий, 42% расхода. YouTube и Discover: 58% расхода, CPA 57–88 €. Search Poliweglan: CPA около 25.5 €, доля показов 44%, потеря из-за рейтинга 56%.
- В PMax канал отключить нельзя (справка Google). В Demand Gen каналы выбираются вручную на уровне группы объявлений, YouTube можно исключить. Display-кампании переводятся в Demand Gen (в течение 2026). См. [[../../База_знаний/Инструменты/Demand-Gen-каналы-и-миграция-Display]].

## Этап A — до 21.10 (без правок в кабинетах)
1. `pmax1_test` и `Poliweglan` не трогаем (цели по CPA 32 € и 25 €).
2. Display-ретаргет: пользователь запускает подъём потолка (`gads_display_bid_ramp.py --loop-min 30`), Claude проверяет по просьбе.
3. Claude готовит (только чтение): список топ-100 YouTube-площадок для исключений; запросы PMax с конверсиями (24 шт.) как кандидаты в ключи Search; проверка канала Ringostat для имени `pmax01_call_test` скриптом `ringostat_channel_matrix.py` (тест на живом сайте).
4. От пользователя: список ассетов для тестового PMax (тексты и картинки; факты только из свежих материалов клиента).

## Этап B — окно правок 22.10
Сначала оценка (показы, расход, звонки Ringostat + формы, CPA) по `pmax1_test` и `Poliweglan`, затем одним пакетом (таблица плана → «да»):
1. Исключения площадок на уровне аккаунта (детские YouTube-каналы и ролики) — действуют на все кампании.
2. `pmax1_test`: слабые группы (`ци`, `no signal`, `зп`) на паузу по правилу «расход от 100 € и CPA выше 64 €»; новая группа `interests` (4 интереса: Lawn Care & Gardening Supplies, Outdoor Items, Landscape Design, Business & Industrial Products).
3. Аудитория `Конкуренты`: убрать свой домен и дубль, добавить `tunelefoliowe.eu`, `alistan-shop.com`, `cieplarnia.pl`, `wesolyrolnik.pl`, `szklarnie-online.eu`.
4. `Poliweglan`: добавить в ключи запросы, которые дали конверсии в PMax (размерные и «z poliwęglanu»), по группам размеров; решение по цели по CPA.

## Этап C — 23–24.10: тестовый PMax `pmax01_call_test` (клик по номеру)
Гипотеза пользователя: цель «клик по номеру» дешевле и срабатывает чаще, алгоритм быстрее набирает сигнал; звонки идут на статический номер Ringostat и меряются там.
- YouTube в PMax отключить нельзя; запуск после исключений площадок (этап B), чтобы старт был чище.
- Структура (решение 2026-10-08 по практике агентства и данным `pmax01`): три группы по типу сигнала с общими ассетами — `call_test_search_themes` (42 поисковые темы), `call_test_interests` (4 in-market интереса покупателей CRM), `call_test_competitors` (новая аудитория из 17 доменов конкурентов). Вариант «все сигналы в одной группе» — запасной.
- Параметры (согласованы в обсуждении, ждут «да»): новая кампания на паузе; Maximize conversions, цель по CPA около 12 €; бюджет 40 €/день (не меньше 3× CPA); оптимизация только по клику по номеру; 7 дней без правок; ассеты из группы `search themes`.
- Успех: уникальные звонки Ringostat на статическом номере. Стоп: расход 250 € и меньше 3 звонков (у `pmax1_test` около 1 звонка на 45 €).
- Риск: два PMax в одном аккаунте делят аукционы друг с другом; результат `pmax1_test` на эти дни читать с оговоркой.
- Против гипотезы: в сентябре `pmax01` на клике по номеру дала 12 конверсий по Ads и 0 звонков по её номеру; `demand_gen` — 32 клика по номеру и 7 звонков.

## Этап D — после 26.10, только если Display-ретаргет показал данные: Demand Gen с выбором каналов
Идея пользователя: усилить показ на целевых площадках вне PMax.
- Новую Display-кампанию создавать сразу в Demand Gen (позже в 2026 классический Display создать будет нельзя).
- Каналы вручную: Google Display Network (при желании плюс Discover), YouTube выключен; аудитории — lookalike по CRM-списку (id списка 5%: 1.1 млн), in-market из Audience insights; таргетинг и исключения площадок.
- Параметры для согласования позже: бюджет 20–30 €/день, 14 дней, цель — реальный звонок (статический номер Ringostat, своя пара «канал + пул»); стоп-правило 250 € и меньше 3 звонков.
- Против: прошлый `demand_gen` в сентябре — 737 €, 7 звонков по Ringostat (около 105 € за звонок), но там была цель «клик по номеру» и все каналы.

## Приоритет по уверенности (мой совет)
1. Поиск (Poliweglan и ключи из запросов PMax): самый дешёвый крупный источник, данные есть.
2. Исключения площадок и перестройка групп PMax: дёшево, риск небольшой.
3. Тестовый PMax на клике по номеру: гипотеза, есть данные против, с жёстким стоп-правилом.
4. Demand Gen без YouTube: самое неопределённое; только после данных по Display-ретаргету.
