Как считается

  1. Цена, клики, показы: Google Ads — из Google Ads API по аккаунту целиком; Facebook — из BigQuery adwhite.fb_stats_profimet (там доллары, в евро пересчитано по курсу из параметра --usd-eur).
  2. Конверсии (наш режим, решение пользователя 2026-11-09) = звонки + формы в ОДНОЙ лестнице 60 дней на номер. Звонки — входящие из Ringostat (Google Ads, Google SEO, Facebook, No Source), формы — из выгрузки CRM без тестовых номеров. Первое обращение номера засчитывается; следующие в пределах 60 календарных дней от последнего засчитанного — повторы (окно они не продлевают); в один день первым считается то, что пришло раньше по времени. В лестнице стоят и обращения без рекламного источника (SEO, органика): номер уже обращался. В заявки идут только звонки Google Ads / Facebook и формы с рекламным источником. Форма с меткой Google Ads / Facebook в CRM — как есть. Форма «Нет метки» проверяется по следам: gclid в CRM, Supabase profimet_leads по телефону, таблица заявок Tilda по телефону, GA4 form_submit в ту же минуту (±6 мин, если событий несколько — не используется). Нашли рекламу — форма идёт в Google Ads / Facebook; нашли не рекламу (прямой заход, органика, реферал) или не нашли ничего — не засчитывается. Минутный срез GA4 хранится около 60 дней, для форм старше — только Supabase / Tilda / gclid. Facebook в нашем режиме — ТОЛЬКО cpc (решение 2026-11-09): звонок — utm_source=facebook и utm_medium=cpc; форма с меткой Facebook — только при utm_medium=cpc (facebook / free не считается); форма без метки — только GA4 facebook / cpc или адрес с facebook и utm_medium=cpc; facebook.com / referral и fbclid без cpc не считаются (в режиме «как у клиента» Facebook — любой источник с facebook). Засчитываются обращения с 2026-08-01.
  3. Звонки: входящие звонки Google Ads и Facebook, засчитанные по правилу выше; у «Нет метки» звонков нет.
  4. Продажи (наш режим): проданные заказы — у заказа есть «Дата продажи»; в период заказ попадает по ДАТЕ ПЕРВОГО КАСАНИЯ (первая строка контакта номера в окне 60 дней до первой строки заказа), то есть по дню, когда возник контакт (когорта). Поэтому последние дни периода недосчитаны: колонка «Продажи: ожидается» = продажи когорты ÷ доля продаж, созревшая к её возрасту (кривая считается по заказам с касанием старше 60 дней). В наш отчёт входят только продажи с РЕКЛАМНЫМ первым касанием в окне 60 дней: «Телефон» (звонки без рекламной метки) и «Нет метки» без найденной рекламы не включаются, их число показано под таблицей; форма «Нет метки» перед этим проверяется теми же следами, что заявки (gclid, Supabase, Tilda, GA4; Facebook только cpc). Считаются ЗАКАЗЫ, не штуки: количества товара в выгрузке нет. Заказ, отменённый после продажи, остаётся в продажах, его число показано отдельно под таблицей. Источник продажи — самое раннее обращение этого номера (звонок или форма) на любом из двух сайтов ProfiMet (основной и SEO) в 60 днях до первой строки заказа: если оно SEO, продажа не рекламная, даже если потом были рекламные звонки. Формы в заявках считаются по выгрузке CRM (сервер), а не по Google Analytics 4. В режиме «как у клиента» продажа привязана к колонке «Дата заказа».
  5. % конверсии = Конверсии ÷ Клики; Цена заявки = Цена ÷ Конверсии; % продажи = Продажи ÷ Конверсии; Цена продажи = Цена ÷ Продажи; CTR = Клики ÷ Показы; Цена клика = Цена ÷ Клики. «Итого»: цена, клики, показы — Google + Facebook; конверсии и продажи — по всем строкам.
