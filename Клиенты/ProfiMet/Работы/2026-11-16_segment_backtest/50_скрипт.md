### Шаг 1. Вердикт устойчив? (k = 3, окна 1, 2, 3, 4, 6 нед.; `segment_backtest_step1_stability.csv`)
Простыми словами: сегмент объявлен «тратит впустую» (0 конверсий и расход не меньше 3 x T). Если вердикт верен, в следующие недели он должен давать меньше конверсий, чем «как в кампании без него». Отношение 1 = «как в среднем», меньше 1 = «правда хуже». Доверительный интервал (ДИ) 95 % получен перебором выборок с повторами по сегментам (бутстреп, 2000 повторов): показывает, насколько число скачет от случайности.
Подтверждены оба горизонта (верх ДИ < 1):

|---|---|---|---|---|
| hour | 2 нед. | 5,37 / 12,54 (0,64) | 12,56 / 21,66 (0,85) | 16 (8) |
| hour | 3 нед. | 8,74 / 18,03 (0,73) | 22,96 / 33,90 (0,97; Холм 0,12) | 22 (12) |
| assetgroup | 1 нед. | 0 / 0,02 (0,00) | 0 / 0,56 (0,00) | 2 (2) |
Остальные окна и срезы - не подтверждены: интервал включает 1 («вердикт не предсказывает»), либо флагов нет, либо флаг у одного сегмента (интервал не определён). Например, группы объявлений, окно 2 нед.: 21,70 / 17,23 при горизонте 1 нед. (отношение 1,26, верх ДИ 1,70); дни недели - отношения 0,90-1,21 около 1 при всех окнах.

Калибровка e^-k (`segment_backtest_step1_calibration.csv`): простыми словами - если заявки приходят случайно, у сегмента с расходом S доля «ни одной конверсии» должна быть e в степени минус (S x конверсий на € по кампании). Сравнивается ожидаемая доля с наблюдаемой (интервал Уилсона - диапазон, в котором с 95 % лежит истинная доля при данном числе наблюдений). Корзины S/T: [0;1), [1;1,5), [1,5;2), [2;2,5), [2,5;3), [3;4), [4;5), [5;бесконечность) - границы не утверждены.

### Шаг 2. Выбор окна (`segment_backtest_step2_windows.csv`, `segment_backtest_step2_tests.csv`)
Простыми словами: прогноз конверсий сегмента на следующую неделю = расход этой недели x ставка (конверсий на €), посчитанная по W неделям и подтянутая к уровню кампании. Ошибка - девианс Пуассона (мера расхождения прогноза и факта для счётных данных, меньше = лучше); сравнение окон - парные разности по сегментам, бутстреп, поправка Холма (чтобы при множестве сравнений случайные «значимые» не считались). Эталон - прогноз по ставке кампании без данных сегмента.

### Шаг 3. Порог k (`segment_backtest_step3_threshold.csv`)
Простыми словами: чем больше k, тем реже мы называем сегмент плохим. «Ложная тревога» - сегмент с флагом, который в следующие 2 недели потратил хотя бы T и при этом дал заявки дешевле T. Нужна наименьшая k, при которой даже верхняя граница доли ложных тревог не выше 5 %.
Наименьшая верхняя граница Уилсона по срезам (окно, k, флагов с расходом после >= T / ложных): dow 19,4 % (1 нед., 2,5; 16 / 0); hour 24,2 % (2 нед., 1,5; 60 / 8); network 56,2 % (1 нед., 1; 3 / 0); device 49,0 % (3 нед., 1; 4 / 0); adgroup 40,8 % (2 нед., 1,5; 27 / 6); keyword 79,4 % (1 нед., 1,5; 1 / 0); assetgroup 70,0 % (1 нед., 1; 6 / 2).
Строка k = 3 (окно 2 нед.): hour - флагов 16, с расходом после >= T 15, ложных 1 (6,7 %, верх Уилсона 29,8 %), ожидаемо ложных при чистом Пуассоне 23,75 (число сегмент-дат под риском 477 x e^-3), расход флагов за следующие 2 недели 1000,0 €. Все строки сетки и окна - в CSV.
