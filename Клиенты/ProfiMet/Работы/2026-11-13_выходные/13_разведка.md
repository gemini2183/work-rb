## Расхождения и ошибки по ходу
- `gads_campaign_settings_xlsx.py` подписывает «DISAPPROVED» все ключи всех пяти кампаний, включая Brand, который показывается. По коду (grep строки 136–142) поле `ad_group_criterion.approval_status` расшифровывается перечислением `PolicyApprovalStatus`, а для ключей это другое перечисление (APPROVED=2, DISAPPROVED=3); у `PolicyApprovalStatus` значение 2 = DISAPPROVED. Вывод: колонка «Одобрение» у ключей в этой выгрузке недостоверна (гипотеза по нумерации перечислений, напрямую не проверена). Одобрение объявлений (поле политики объявления) расшифровано верно. В `База_знаний/Проблемы/` я не искал и не писал (запись — по плану через `wiki-recorder`).
- `gads_campaign_settings.py` показал только включённые кампании (3 из 5 запрошенных): weekend и generic на паузе в таблицу не попали.
- Первый запуск `page_tracking_check.py` по главной оборвался моим `timeout` (не сбой сайта, код ответа 200); перезапущен один раз без таймаута — результат в отчёте. Итого по главной два запуска, по остальным по одному.
- `10_данные.md`: «воскресенье не работает ни одна кампания» подтверждено для ВКЛЮЧЁННЫХ; у PAUSED weekend расписание содержит воскресенье 9–16. Остальные проверенные факты (Brand сб 8–18, Poliweglan и montaz сб 9–16, weekend PAUSED 366.91 €, нули 09.07–06.10) подтверждены.
