# Проверка ассетов `search / montaz`

## Резюме
Факты в ассетах совпадают со страницей. Найдено одно несоответствие (описание быстрой ссылки «Zamów montaż») и пробелы: мало быстрых ссылок, нет фото с монтажом. Страница сама слабее объявления: нет кнопки к калькулятору.

## Предложения по ассетам (в кабинет только по «да»)
1. Описания ссылки «Zamów montaż»: «Wybierz model i długość» / «Zostaw numer, oddzwonimy».
2. Две новые ссылки: «Gdzie montujemy?» (`#rec5305610703`, раздел FAQ с зоной) и «Samodzielnie czy z montażem» (`#rec5305264303`, блок выбора, скручиваемая конструкция без сварки).
3. Фото монтажа или команды — если клиент пришлёт (реальные, без ИИ), добавить в кампанию.

## Замечания к странице (клиенту / исполнителю сайта)
1. Нет ни одной ссылки на калькулятор: в шапке и первом экране нет кнопки «Kalkulator montażu» (`#pm-kalkulator`). Блок «montaż» начинается на 2832 px, калькулятор на 3456 px; между ними каталог товаров на 2100 px.
2. Видео первого экрана грузится с личного репозитория GitHub (`github.com/oleksii-savchenko/video/raw/…/0815.mp4`): внешняя зависимость, может пропасть или тормозить.
3. Нет `h1` и `description` на странице.
4. Часы: шапка «9–17», FAQ «9–18».
5. Окно заказа без скрытого `ga_client_id`.
