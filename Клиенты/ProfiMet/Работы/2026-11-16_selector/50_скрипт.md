## Шаг Б: бэктест
Команда: `PYTHONUTF8=1 python period_backtest.py --backtest --client ProfiMet --to 2026-11-15` (панель из шага А; вывод целиком - `backtest_stdout.txt`).

Методы и формулы (для аудита):
- Окно k недель (кандидат а): недельные суммы заявок последних k целых недель; Gamma-Пуассон с априором Gamma(0,5; 0) (Джеффрис), предсказательное распределение - отрицательное биномиальное; эффект дня недели не нужен, так как недели целые.
- Динамическая модель (б): дневная Gamma-Пуассон модель с «степенным забыванием» (power steady model, Harvey–Fernandes 1989; Smith–Miller 1986; West–Harrison, гл. 14): a←δ_d·a+y, b←δ_d·b+s_день недели; s - факторы дня недели, оцениваются по прошлым данным (≥4 недель, иначе =1). Недельный прогноз - NB со средним a'/b'·7 и сверхразбросом φ (1/r = 1/a' + φ).
- Забывание δ (недельное) и φ выбираются на каждом шаге по накопленному предсказательному логарифмическому правдоподобию прошлых прогнозов (rolling-origin, без заглядывания вперёд); у окон φ выбирается так же. Выбранные δ: медианы 0,30 (аккаунт), 0,40 (Brand), 0,50 (Poliweglan), 0,40 (pmax01, pmax1_test, szklarnia/tunel) - не на границе сетки (нижняя граница 0,05 выбрана в 0 % недель). У szklarnia/tunel φ упирается в верхний край сетки (85 % недель), сетку φ для него надо расширять.
- Ошибка: WAPE = Σ|y−ŷ|/Σy; MASE = MAE/MAE(прогноз «как на прошлой неделе»), >1 хуже наивного; покрытие = доля недель, где факт в [2,5 %; 97,5 %] квантилей NB (дискретность делает номинал консервативным).
- Тест Диболда–Мариано (1995), горизонт 1, потеря |ошибка|, малая выборка: поправка Харви–Лейборна–Ньюболда (1997), t-распределение T−1; односторонняя гипотеза «динамика точнее окна». Множественные сравнения: поправка Холма (1979): внутри объекта по окнам; для общего окна - по всей семье (6 объектов × 7 окон = 42 пары), α = 0,05.
- Кандидат (в) иерархический: НЕ реализован (причина: нет утверждённой схемы подтяжки кампании к аккаунту, кампании включаются/выключаются). Dynamic+иерархия остаётся пробелом.

## Как встроить селектор и обнаружение излома (не реализовано)
- Селектор: для каждой кампании на каждой неделе считать прогноз кандидатами (окно 1..K и динамика), выбирать кандидата по накопленному предсказательному правдоподобию/ошибке прошлых недель; «окно 1 нед.» как запасной результат, если разница не значима. Нужно утвердить: α, n_min прогнозных недель, w_disp, сетки δ и φ, min_total_leads, правило «ничья» (при не отвергнутой разнице брать более простое - окно), хранение журнала предсказаний (`Калибровка_методов.md`).
- Излом: BOCPD (Adams–MacKay 2007) на дневных рядах заявок (Gamma-Пуассон сопряжён, реализуется на numpy) и цены клика (клики/расход); без `ruptures`. Журнал правок - кандидаты дат, подтверждаются изломом в окне ±N дней (N - утвердить). Нужно утвердить: априор длины режима (hazard) - оценивать по истории аккаунта, а не задавать; проверить на известных датах правок (12.11, 03-04.11).
- CausalImpact: библиотеки `causalimpact`/`tfcausalimpact` не установлены (нужны `pip install tfcausalimpact` или `pycausalimpact`, тянут tensorflow-probability/statsmodels). Замена из имеющегося: разность разностей по контрольным кампаниям (numpy), структурная модель не воспроизводится.
