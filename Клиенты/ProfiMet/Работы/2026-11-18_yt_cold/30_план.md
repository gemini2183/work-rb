## Резюме
1. Сторож: в `guard_config.yaml` меняется одна цифра, `target: 17` -> `33`. Остальное (grace 2, total_limit 300, abs_mult 2) остаётся.
2. Пауза за день без заявок практически наступит по жёсткому пределу 2 x бюджета = 60 € (допустимый по цене заявки расход 66 € выше). Вероятность ложной паузы e^(-60/33) = 16%.
3. Стоп "около 100 €": даёт общее правило сторожа `dry_mult 3` x 33 = 99 € расхода без заявок подряд (ложная пауза e^-3 = 5%). Отдельно в конфиг ничего вписывать не нужно.
4. РИСК: счёт "без заявок подряд" сторож берёт из своего лога по ЗАВЕРШЁННЫМ дням: на 18.11 уже 90,39 € (5,63 + 52,11 + 32,65). Окна "с момента смены стратегии" в конфиге нет. Если после включения сторож перезапущен до включения или не заметил включение, он поставит паузу почти сразу (99 - 90,39 = 8,6 €). Нужен порядок включения, см. «Допущения» п. 2.
5. Мусорные каналы: 38 каналов, 1,93 € (8 кликов) за 13-17.11, CSV готов, validate_only пройден (38 к добавлению, 0 уже есть).
6. Скрипт исключения работает ТОЛЬКО на уровне аккаунта: затронет yt_warm и все остальные кампании аккаунта. Скрипта для исключения каналов на уровне одной кампании нет (`gads_add_campaign_negatives.py` умеет только ключевые слова).
7. Эффект исключения мал: 1,93 € из 47,73 видимых (4%, около 2% всего расхода), на темп расхода не влияет (20_анализ.md, разд. 2 и 8, п. 5). Приоритет низкий.
