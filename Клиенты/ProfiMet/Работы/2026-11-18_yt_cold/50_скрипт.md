# 50. Скрипт: универсальный разрез кампании Google Ads

Скрипт: `D:\GitHub\work-rb\Скрипты\gads_campaign_breakdown.py` (только чтение, `--execute` нет). Первая версия называлась `gads_yt_slice.py` под Demand Gen; по поправке пользователя заменена общим скриптом, старый файл и его CSV удалены.

## Что сделано
Один скрипт для Search, PMax, Demand Gen, Display, Video. Тип берётся из `advertising_channel_type`, на каждый разрез выбирается свой ресурс GAQL, неподдерживаемое печатается строкой «не поддерживается для <тип>: <причина>». Каждый разрез в своём try/except, ошибки API дословно. Разрезы `--by`: day, hour, dow, device, network, audience, ad_group, asset, placement, conversion_action, change_history.

Переиспользовано только `gads_stats.GOOGLE_ADS_YAML` (путь к ключам). `gads_pmax_channel_split.py`, `gads_pmax_placements.py` и `state_digest.change_events` не импортировал: они печатают внутри функций и заточены под одну кампанию или тип, `change_events` не фильтрует по кампании.
