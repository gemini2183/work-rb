# 50_скрипт: звонки из объявлений ProfiMet берём из call_view

Скрипт: `D:\GitHub\work-rb\Скрипты\leads_standard.py` (только чтение). Клиент: только ProfiMet (Google Ads 7552781705).

## Что сделано
Добавлен флаг `--calls-from-ads {ringostat|call_view}` (в `month_leads` — параметр `calls_from_ads`). По умолчанию `ringostat` = старое поведение, код потребителей (`pace_vs_plan.py`, `sales_pace.py`, `period_backtest.py`, `state_digest.py`, сторож через `live_maps`) не менялся и их цифры не меняются.

Режим `call_view`:
1. Звонки пула Ringostat «Google CPC calls from ads» из заявок убираются.
2. Каждая строка `call_view` (кампания известна Google Ads) становится заявкой.
3. Исключение: дубль. Строка не добавляется, если есть звонок другого канала Ringostat (статика PMax, динамика, поиск) со временем в пределах ±5 с (`DUP_SEC`). Один звонок гасит одну строку.
4. Динамика, статика PMax, формы Supabase не меняются. Подстановка кампании из `call_view` в звонки с неизвестной кампанией (статика PMax) осталась как раньше (±180 с).

## Дубли (проверено до правки)
Срез: `call_view` с 01.08.2025 (214 строк; данные в нём с 14.01.2026), уникальные звонки Google Ringostat без пула calls from ads.
- Совпало по времени в пределах ±180 с: 54 строки (ноябрь: 2).

- Остальные 51 (в ноябре обе: 178 с и 178 с, динамика) случайные: другой человек в те же минуты.

Поэтому для дублей введён `DUP_SEC = 5`, источник — замер сдвига у 209 пар (0–4 с, среднее 1,35 с). Это единственный новый порог, он отличается от вашей инструкции «±180»; решение за пользователем.
- Результат: дублей 3 за всё время (все не динамические), в ноябре 0.

## Фильтры
В коде звонков-заявок фильтров по длительности и статусу нет. Есть: `call_type=in`, источник Google, `excluded_campaigns`, уникальность 60 дней по номеру. К `call_view` применено всё, что применимо: нового фильтра по длительности/статусу нет. Уникальность по номеру у `call_view` недоступна (номера нет), повторные звонящие не отсекаются. Строк с длительностью 0 с среди добавленных: 8 за всё время, 0 в ноябре (оставлены, как и в Ringostat).
