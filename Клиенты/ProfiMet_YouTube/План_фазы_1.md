## Допущения (проверить)
1. Расписание: пн–пт весь день (решение было только «будни»; часы 9–17 клиента на сайте — идея в [[../../Бэклог_идей]], не решена).
2. Два отдельных объявления по одному ролику, чтобы Ringostat различал варианты по `utm_content`; Google распределяет показы между ними сам. **Принято пользователем 03.11.**
3. Номера: два новых (48739103340, 48739103479), а не два из динамического пула (так динамический пул Search и PMax не трогаем); третий остаётся на холодную. Предыдущий вариант из пула (48579772685, 48579774020) снят.
4. Цели кампании: форма, звонок из объявления, звонок с сайта; клик по номеру вторичный; «engaged-view» (просмотр без клика) в цели не включаем, если мастер даёт такой переключатель (проверить).
5. Название бизнеса «ProfiMet», кнопка «Learn more» (допустимые значения проверит `validate_only`).
6. Логотип в виде прозрачного PNG; принимает ли Ads прозрачный фон, проверит `validate_only`, при отказе подложим белый квадрат.
7. Гео и языки как у `dg_*`: вся Польша, pl и en.
8. Аудитория частично пересекается с `dspl_rtg_basket` (Display, корзина); исключения между ними не ставим.
9. Названия «yt_warm», «yt_warm_g1» и utm — рабочие, меняются без последствий до включения.
10. Продажа и конверсии «Ads» считаем только по формам и звонкам, не по просмотрам (план аналитики п. 4).
