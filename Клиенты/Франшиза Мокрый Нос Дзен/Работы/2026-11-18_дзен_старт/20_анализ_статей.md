## 4. Математика бюджета 50 000 ₽ с НДС на месяц

Бюджет 50 000 ₽ с НДС = 40 984 ₽ чистого расхода по базе API (при НДС 22 %; при 20 % - 41 667 ₽). Допущение: 50 000 ₽ - это деньги, которые клиент платит, и НДС сверху лежит на расходе API.
