# 16. Ссылки в статьях: что видит читатель (только чтение, 2026-11-18)

## Вердикт
1. Предыдущий вывод «в CTA UTM нет» неверен для читателя. В редакторе href = `https://franchise.mokryinos.ru/dzen` без меток; на публичной странице сервер ПромоСтраниц дописывает метки в href при выдаче. Источник: статья по ссылке пользователя, публичная страница `https://franchise-mokryinos.promo.page/media/x-6a5dfc4ccdc5467ae9e82491_0_0` (href кнопки «Получить бизнес-план» прочитан в DOM).
2. Статья по ссылке пользователя (рынок и тренды, кампания 2404 М25-44): публичный href = `https://franchise.mokryinos.ru/dzen?utm_source=yandex.promopages&utm_medium=article&utm_campaign=Промостатья: рынок и тренды 1 / М25-44 / интерес_франшиза / рся / #dzen / 2404&utm_content=market&utm_term=6a5dfc4ccdc5467ae9e82491`. Метка `utm_content=market` вшивается из настроек кампании (экран «UTM-метки»), в самом тексте статьи её нет. Блок «Вы только что видели, как устроен рынок» покажется.
3. ID в публичном адресе (`6a5dfc4c...`) не равен UUID из адреса редактора (`a2e6e962-...`): это ID карточки «статья + кампания» (на экране кампании «ID статьи»). Копия под каждую кампанию получает свой ID и свои метки.
4. Правило меток зависит от кампании: у кампаний 2404, 2602-1 (читал через 699eb80c), и по Метрике 2603-1 и 2607-1 `utm_content` = `history` или `market`. У остальных кампаний `utm_content` = «Заголовок_ID» (например `Как я преобразила свою жизнь...`_ID), блоков /dzen они не включают. Источник: публичные страницы 25 ID (таблица 2) и `Статистика/metrika_promopages_articles_...csv`.
5. Из Метрики (что реально пришло): 2603-1 Ж-история `history` 955 визитов, 2603-1 М-рынок `market` 636, 2404 Ж-рынок `market` 235, 2602-1 `history` 255, 2607-1 поиск `history` 5. До 12.03.2026 у кампании 2602-1 в utm_content шли заголовки, с 13.03.2026 - `history`.
6. Не только /dzen: у статей из кампаний #promo (2512-1, 69970bd3, 6943...) CTA ведёт на `/promo`, из #franchise (2511-1: 691c6d23, 691c6dbb) на `/franchise`, у «Цифры и факты» две кнопки: `/dzen` и `/franchise/`. Блоки /dzen по метке получают только ссылки на /dzen.
7. Уникальных статей по заголовку и обложке: 5 тематических групп плюс черновики (см. таблицу 1). Подтверждено частично: «Как я преобразила...» и «История успеха...» - один материал «Моя история 1» с разными заголовками (общая обложка в ленте, один и тот же ID карточки в Метрике у обоих заголовков). Тексты целиком между копиями не сличал.
8. Не сделано: ID карточек без трафика в Метрике (в том числе карточки 2603-1 М-рынок и 2607-1, 2404 Ж и «дочит+скролл») - публичные адреса не получены, ID на карточке не раскрывается (кнопка «ID» копирует в буфер, прочитать не удалось). По ним значение utm_content взято из Метрики, а не из href. API списка публикаций требует токен, его не искал и не использовал.
9. Ничего не сохранял, не публиковал, формы не отправлял. Открывал публичные страницы по ID и читал href.
