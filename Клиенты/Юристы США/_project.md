## Технический контекст

Агентство Adwhite (Google Ads), не Redbird (Директ) — общая таблица клиентов
`SHEET_URLS["adwhite"]` в `Скрипты/_config.py` (см. [[../../Инфраструктура|Инфраструктура]]).
Клиент НЕ заведён строкой ни на вкладке "Adwords", ни на "Google_Ads_API" общей
таблицы Adwhite (проверено 2026-08-06) — в отличие от остальных Adwhite-клиентов.
customer_id пришлось искать в прод-репозитории `google-cloud-jobs` напрямую.

Два подпроекта — отдельные Google Ads аккаунты (не один аккаунт с фильтром по
названию кампании, как у [[../Корогва/index|Корогвы]]):
- **Andverpersonalinjury** (сайт landverpersonalinjury.com, бренд в объявлениях
  "Landver Law") — customer_id `213-621-6123`
- **Desertinjurylaw** — customer_id `143-548-8870`

Оба доступны через один и тот же MCC `login_customer_id` `302-348-6398`
(источник: `google-cloud-jobs/adwhite/func/gads_andverpersonalinjury/main.py` и
`.../gads_desertinjurylaw/main.py` — per-client Cloud Function с захардкоженным
customer_id, не через общую таблицу; см. [[../../Инфраструктура|Инфраструктура]]
про паттерн двух поколений job'ов). Локальный скрипт вики `Скрипты/gads_ads_dump.py`
принимает `--customer-id` напрямую, без похода в таблицу — по этой же причине.
