## 4. Допущения (проверить до «да»)
1. Цена заявки на остаток 79 $ допустима как предел для маржинальных заявок — **это плановая арифметика, не оценка ценности заявки** для клиента; средний чек по сегментам (часы / золото / бриллианты) мне не известен. Особенно важно для watches / lux (89 $ за заявку при плане 70).
2. Клиент согласен расширять гео на весь Los Angeles для высоких чеков: в кампаниях есть минусы по названиям городов (santa monica, glendale, pasadena, thousand oaks, chatsworth, tustin и др., 105–107 кампанийных минусов) — кто-то ограничивал географию сознательно, причина не зафиксирована.
3. Заявка = «Calls from ads» + формы + Ringostat-звонки из сайта (в jewelry / non-lux за 13.09–11.10: 33,2 из ≈ 48; в watches / non-lux 18 из ≈ 24); качество «Calls from ads» не проверяется (см. [[Решения]]).
4. Группы и минусы: целевые группы названы по их текущим именам; **в группах jewelry / non-lux есть групповые минусы «sell», «buy/buys», «buyer(s)», в watches / lux — «rolex», в diamonds — «ring(s)» (групповой) и «loose» (кампанийный)** — они маршрутизируют запросы между группами. Новые группы «harvest» нужно собирать с учётом этого (перенос минусов на новую группу), иначе ключи не получат показов.
5. Объёмы Keyword Planner округлены (10, 20…); для узкого гео это порядок, не точное число.
