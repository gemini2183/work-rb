# Журнал изменений — Andverpersonalinjury (Landver Law)

**Назначение.** Единый список того, что мы реально сделали в Google Ads, OpenAI Ads, LSA, Ringostat, GA4/GTM, с состоянием «до» и «после». Отличие от остальных файлов: [[Решения]] хранит стратегию и рассуждения, логи кампаний — рутинные правки, а здесь только факты изменений, по одному блоку на изменение. Этот файл читает агент ежемесячных отчётов клиенту.

**Формат записи** (заголовок парсится: `grep "^## \["`):

```
## [ГГГГ-ММ-ДД] И-NNN | Канал / уровень | Объект | Действие | Было → Стало
- Зачем:
- До (снимок / база метрик):
- Проверка после (прочитано обратно из аккаунта?):
- Откат:
- Что измерять и когда:
- Результат на сегодня: (измерено — с цифрой и периодом; гипотеза — так и написать; пока нет данных — так и написать)
- Для отчёта клиенту (EN): одно предложение простым английским о пользе действия, без выдуманных результатов
- Связано: [[Решения]] запись …
```

**Правила для агента отчётов.**
- В клиентский текст идёт только «Для отчёта клиенту (EN)» и измеренные цифры из «Результат на сегодня». Гипотезы не подавать как результат.
- Показы, клики, расход брать свежо из отчётов (Insights/Google Ads/GA4), а не из этого файла: здесь они приведены как срез на дату записи.
- Записи с пометкой «ретро» восстановлены из [[Решения]] после факта (нет снимка «до» с цифрами); про них писать осторожнее.
- Один раз заведённый ID не меняется; итог эффекта дописывается отдельной строкой «Итог …» под записью.
