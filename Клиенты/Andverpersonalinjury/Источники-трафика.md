# Источники трафика — Andverpersonalinjury (Landver Law)

Консолидированная карта всех каналов, через которые Google Ads показывает объявления
этого аккаунта (customer_id `213-621-6123`). Собрано на основе
`Статистика/gads_campaigns_breakdown_2026-06-01_to_2026-08-19.csv` (период
2026-06-01 → 2026-08-19, снято `Скрипты/gads_campaigns_breakdown.py`).

**Важно (см. [[../../База_знаний/Паттерны/Google-Ads-аудит-кампании-алгоритм-и-ошибки-смешения-данных|методологию]]):**
все числа ниже разделены по `advertising_channel_type` (SEARCH-кампания vs
PERFORMANCE_MAX vs DISPLAY) в первую очередь, и только внутри него — по сети показа
(`ad_network_type`). Предыдущая версия этого документа (до 2026-08-19) смешивала
Network=SEARCH из Performance Max с Network=SEARCH обычных Search-кампаний в одну
сумму — из-за этого ошибочно называла "чистый Search" здоровым каналом
($39.33/конверсия), хотя реальный чистый Search дал только 1 конверсию за весь
период. Ошибка найдена пользователем по расхождению со скриншотом кабинета,
разобрана в [[Решения]], запись 2026-08-19 "обнаружена и исправлена критическая
ошибка агрегации".

## 1. Search-кампании — чистый Google Search (Network=SEARCH внутри ручных кампаний)

**Статус: НЕ здоровый канал вопреки первому впечатлению — почти не получает трафика.**
126 кликов / $678.79 / только 1 конверсия за 2.5 месяца по ВСЕМ ручным Search-кампаниям
вместе. Причина подтверждена через Impression Share (`Скрипты/gads_impression_share.py`,
см. [[Решения]] запись 2026-08-19): на двух активных LA-тестовых кампаниях
`Impression_share=9.99%`, `Lost_IS_budget=0%`, `Lost_IS_rank=90%` — бюджет НЕ
ограничивает показы, проблема в ставке/Quality Score относительно рыночного Ad
Rank конкурентов. Порог входа на первую страницу чистого Search в этой нише/гео —
$60+/клик (подтверждено пользователем через Keyword Planner suggested bid и ручной
режим ставок), независимо от длины/специфичности фразы — см.
[[../../База_знаний/Паттерны/PPC-Personal-Injury-США-борьба-с-дорогим-и-мусорным-трафиком|Паттерны/PPC-Personal-Injury-США]],
раздел 3.

## 2. Search Partners внутри Search-кампаний — доминирующий, но нерезультативный канал

**Статус: подтверждённая проблема, решение готово, ждёт исполнения (см. [[Задачи]]).**

2028 кликов / $2425.84 / только 9 конверсий за 2.5 месяца — партнёры получают **94%
всех кликов** и **78% всего расхода** ручных Search-кампаний, при этом Cost/conv
$269.54 против $678.79 у чистого Search (формально дешевле за конверсию, но на базе
всего 9 vs 1 конверсии — статистически ненадёжно). Разбивка по кампаниям:

- **`search / car accident / ca - google search + network`**: 1357 кликов / $1493.58 /
  8 конверсий ($186.70/конв.) — крупнейший расход на партнёров в аккаунте.
- **`search / all injuries`**: 466 кликов / $590.10 / 1 конверсия.
- **`search / all injuries / geo - la specific`**: 79 кликов / $102.95 / **0 конверсий**
  — часть трафика подтверждённо НЕ из целевого гео (search terms содержат "orlando",
  "atlanta", "houston", "chicago", "colorado", "nashville", "phoenix" — см. [[Решения]]
  запись 2026-08-19), несмотря на таргетинг по 118 ZIP-кодам вокруг офиса.
- **`search / all injuries / kw -  la specific`**: 13 кликов / $10.27 / 0 конверсий.
- **`search / all injuries / s& n / lp - tilda`**: 98 кликов / $206.14 / 0 конверсий.

Детальный разбор площадок (search-arbitrage домены) — в

## 3. Performance Max (`pmax / ca`) — на паузе, но исторически лучший канал

**Статус: наиболее конверсионный канал по факту исторических данных.** 40 конверсий
на Network=SEARCH внутри PMax ($30.26/конв.) и 10 на Network=SEARCH_PARTNERS внутри
PMax ($33.78/конв.) — суммарно 51 из 61 конверсии всего аккаунта пришли из PMax.
**Важная оговорка пользователя (2026-08-19, не проверено на практике)**: есть
подозрение, что часть этих конверсий может быть нерелевантными обращениями по
темам, которыми фирма не занимается (например, harassment вместо personal injury)
— PMax таргетируется по широкой теме "Personal Injury" автоматически, без ручного
контроля семантики. Не проверено через прослушивание звонков/CRM — требует сверки
перед тем, как делать вывод "PMax — лучший канал, наращивать бюджет".
YouTube/Content/Discover внутри PMax — минимальный расход, 0 конверсий, не приоритет.

## 4. Display (`dspl / ca`) — на паузе

431 клик / $29.94 / 0 конверсий. Площадки — почти целиком мобильные приложения
(игры, дейтинг, VPN) и разрозненные новостные страницы — типичный автоматический
КМС-таргетинг без контентных исключений, не признак фрода. Низкий приоритет — расход
символический.

## 5. Google Local Services Ads (LSA)

**Статус: не источник трафика ещё — верификация в процессе.** Отдельный от Search
канал (pay-per-lead). Business Verification почти пройдена, блокер — "Lawyer license"
(License check), "Processing" на 2026-08-19. Кампания технически существует со
статусом PAUSED и бюджетом $264.88/день (видно в `gads_campaigns_list.py --all`) —
уточнить, действует ли этот бюджет уже сейчас или это дефолт, ожидающий
разблокировки после завершения верификации (см. [[Решения]], записи 2026-08-19 про
"Save серая"). См.
[[../../База_знаний/Паттерны/PPC-Personal-Injury-США-борьба-с-дорогим-и-мусорным-трафиком|Паттерны/PPC-Personal-Injury-США]],
раздел 4.

## Итоговый приоритет по каналам (2026-08-19, пересмотрено)

1. **Search Partners в ручных Search-кампаниях** — 78% расхода Search-бюджета почти
   без результата, включая подтверждённо нецелевой гео-трафик. Решение готово (см.
   [[Задачи]]).
2. **Ставка/Ad Rank на чистом Search** — 90% потерянных показов из-за ставки/QS, не
   бюджета. Нужно стратегическое решение: поднимать ставку (дороже клик, порог
   ~$60+) или пересмотреть ожидания по объёму на этом бюджете.
3. **PMax** — исторически лучшие цифры по конверсиям, но требует сверки на
   релевантность обращений (подозрение на нецелевые темы) перед тем, как считать
   приоритетным каналом.
4. **LSA** — ждёт завершения верификации.
5. **Display** — низкий приоритет, расход мал.
