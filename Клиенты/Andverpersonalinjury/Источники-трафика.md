# Источники трафика — Andverpersonalinjury (Landver Law)

Консолидированная карта всех каналов, через которые Google Ads показывает объявления
этого аккаунта (customer_id `213-621-6123`), с текущим статусом разбора по каждому.
Собрано на основе `Статистика/gads_network_breakdown_2026-07-20_to_2026-08-18.csv` и
`Статистика/gads_search_partner_placements_2026-07-20_to_2026-08-18.csv` (30 дней,
2026-07-20 → 2026-08-18, снято `Скрипты/gads_search_partners_audit.py`). Детальный
разбор проблемы Search Partners — в
[[../../База_знаний/Паттерны/PPC-Personal-Injury-США-борьба-с-дорогим-и-мусорным-трафиком|Паттерны/PPC-Personal-Injury-США]],
здесь — только карта и статус, без дублирования деталей.

## 1. Search — чистый поиск Google

**Статус: здоровый канал.** 202 клика / $1258.56 / 32 конверсии за 30 дней,
$39.33 за конверсию — лучший показатель по аккаунту. Приоритет — наращивать долю
этого канала, а не оптимизировать его дальше в моменте.

## 2. Search Partners — сеть поисковых партнёров Google

**Статус: подтверждённая проблема, ждёт решения пользователя (см. [[Задачи]]).**

1084 клика / $1516.91 / только 10 конверсий за 30 дней — при этом бо́льшая часть
даже этих 10 конверсий пришла не из Search-кампаний, а из `pmax / ca`. Картина резко
разная в зависимости от кампании:

- **`pmax / ca`**: Search Partners даёт 73 клика / $177.78 / 9 конверсий
  ($19.75/конв.) — **эффективнее**, чем Search той же кампании ($31.03/конв.). Не
  трогать.
- **`search / car accident / ca - google search + network`**: 483 клика / $529.12 /
  **0 конверсий**. Худший результат в аккаунте, кандидат №1 на отключение партнёров.
- **`search / all injuries`**: 369 кликов / $524.83 / 1 конверсия ($524.83 за неё).
  Кандидат №2.
- **`search / all injuries / s& n / lp - tilda`**: 98 кликов / $206.14 / 0 конверсий.
- **`search / all injuries / geo - la specific`**: 60 кликов / $78.83 / 0 конверсий.

Распределение площадок (963 из 1081 строки в placement-отчёте — это Display, не
Search Partners; из оставшихся ~118 строк Search-кампаний бо́льшая часть показов идёт
на кучку malicious/arbitrage-доменов) детально разобрано в
[[../../База_знаний/Паттерны/PPC-Personal-Injury-США-борьба-с-дорогим-и-мусорным-трафиком|Паттерны/PPC-Personal-Injury-США]],
раздел 1a — там же ограничение метода Google Ads (placement exclusion бьёт по всему
аккаунту, а не по кампании) и вывод: отключать через `network_settings` на уровне
конкретной кампании, не через exclusion list.

Топ проблемных доменов (impressions, не клики — API таких данных не даёт по домену):
`reviews.everydayxperts.com/search`, `bozuktus.com/blog/query`,
`wiseinmind.com/search`, `searchjobsplus.com/afs`, `infonowplus.com/afs`,
`selectanswers.com/topic/...`, `www.indiasite.com/get/result`,
`gkinmarathi.in/wp-code` — паттерн URL (`/search`, `/serp`, `/afs`, `/topic/<id>`)
типичен для search-arbitrage сетей, не реальных сайтов с органическим поиском.

## 3. Performance Max (`pmax / ca`)

**Статус: смешанный, не трогать целиком.** Сама кампания распределяет бюджет по
Search, Search Partners, Content (Display), Discover, Maps, YouTube — это видно по
строкам `pmax / ca` во всех сетях network breakdown. Внутри неё Search Partners
эффективнее Search (см. раздел 2) — вероятно, за счёт более широкого
машинного таргетинга PMax, отличного от таргетинга ручных Search-кампаний.
Discover/YouTube/Maps дают минимальный расход (единицы-десятки $) и либо 0, либо
1 конверсию (Maps) — не критично, не разбиралось отдельно, низкий приоритет.

## 4. Display / КМС (`dspl / ca`)

**Статус: не разбирался детально, вероятно нецелевой, но дешёвый.** 431 клик /
$29.94 / 0 конверсий за 30 дней в сети CONTENT — цена клика низкая ($0.07), поэтому
расход символический, но конверсий тоже 0. Placement-отчёт показывает 963 строки
площадок для этой кампании — почти целиком мобильные приложения (App Store/Google
Play — игры, паззлы, соцсети, дейтинг-приложения вроде Badoo/Adam4Adam, VPN,
мессенджеры) и разрозненные новостные/статейные страницы (Fox News и т.п.). Это
типичная картина автоматического КМС-таргетинга без контентных/тематических
исключений, а не признак фрода конкретно под этот аккаунт — но и релевантности для
personal injury здесь нет. Не проверено: сколько показов/кликов Display даёт помимо
`pmax / ca`-присутствия в CONTENT-сети (см. раздел 3); не приоритизировано, т.к.
расход крайне мал относительно Search Partners.

## 5. Discover, YouTube, Maps

**Статус: минимальный объём, не разбирался.** Все три канала показываются только
через `pmax / ca` (нет отдельных Discovery/Video/Local кампаний в аккаунте). Суммарно
$27/30 дней, 1 конверсия (Maps). Не приоритет.

## 6. Google Local Services Ads (LSA)

**Статус: не источник трафика ещё — верификация в процессе.** Отдельный от
Google Ads Search канал (pay-per-lead, не pay-per-click) в рамках того же
customer_id. Business Verification почти пройдена, блокер — "Lawyer license" (License
check), статус "Processing" на 2026-08-19. Бюджет и стратегия ставок пока не
сохраняются в интерфейсе (заблокировано до конца верификации) — см. [[Решения]],
записи 2026-08-19, и [[Задачи]]. Рассматривается как основная альтернатива дорогому
Search (см.
[[../../База_знаний/Паттерны/PPC-Personal-Injury-США-борьба-с-дорогим-и-мусорным-трафиком|Паттерны/PPC-Personal-Injury-США]],
раздел 4).

## Итоговый приоритет по каналам (2026-08-19)

1. **Search Partners в проблемных Search-кампаниях** — решение готово, ждёт
   исполнения (см. [[Задачи]]).
2. **LSA** — ждёт завершения верификации Google, дальше нужна оценка реальной
   эффективности как отдельного канала.
3. **Display (`dspl / ca`)** — низкий приоритет, расход мал, но контентные
   исключения (мобильные приложения/игры) могли бы дополнительно почистить бюджет.
4. **Discover/YouTube/Maps** — не приоритет, объём слишком мал для отдельной работы.
