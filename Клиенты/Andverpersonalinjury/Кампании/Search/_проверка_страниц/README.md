# Проверка страниц Settlement и Car в браузере

Скрипты, которыми проверялись блоки страниц до публикации. Они не пишут ни в Tilda, ни в кабинеты, только открывают локальный макет.

| Скрипт | Что делает |
|---|---|
| `build_preview.py` | Собирает макет Settlement (`settlement_page_preview.html`) из трёх блоков `settlement_quiz_t123.html`, `settlement_body_t123.html`, `settlement_footer_t123.html` и имитированных форм |
| `run_test.py` | Квиз Settlement: 12 сценариев (уровни serious / moderate / developing, 5 персональных строк), кнопка «Back», «Change my answers», события dataLayer, скрытые поля, ссылка tel, якорь, переполнение по ширине на телефоне, ошибки консоли. Сохраняет скриншоты в свою папку |
| `run_full.py` | Макет Settlement целиком на телефоне 390 px и компьютере 1366 px: высота, переполнение, загрузка фото, FAQ, плашка, события |
| `run_car.py` | То же для макета Car (`Tilda_страница_Car\0_maket_prosmotr.html`), плюс проверка квиза и видимости формы A на первом экране |

Легковая страница собирается скриптом `build_car_page.py` (в этой же папке на уровень выше): он читает блоки Settlement, пишет блоки Car и макет в `Tilda_страница_Car`.

Ограничения: скрипты используют жёсткие пути `D:\GitHub\work-rb\...`; выходные скриншоты и `page.html` пишутся рядом со скриптом; на живой Tilda не проверялось (скрытые поля формы и подмена номера Ringostat проверяются только после публикации).
