## Делаешь (только чтение)
1. Разбери каждый текст на утверждения: цифры (годы, количество дел, суммы, проценты), сроки, гарантии и условия («бесплатно», «без предоплаты», «24/7»), акции, география, сравнения и превосходные степени.
2. Для каждого найди источник по иерархии метода. Статус: **подтверждено** (цитата + путь) / **расходится** / **не найдено** / **нельзя доказать**. Оценочные слова без числа («experts», «dedicated») проверять не нужно; проверять факты и обещания.
3. Расходящиеся, не найденные и недоказуемые — предложи замену ТОЛЬКО из источника; допущения называй отдельно.
4. Длины и лимиты: заголовок до 30, описание до 90 знаков; дубликаты; язык текста.
5. У каждой цитаты — путь к файлу и строка/фрагмент; без цитаты статус «подтверждено» не ставь.
