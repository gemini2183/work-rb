## Делаешь (только чтение, из папки `Скрипты`, `PYTHONUTF8=1`)
1. **Страница:** `page_tracking_check.py --url <адрес> --client-folder <Имя>` — один раз; затем `phone_swap_check.py --client-folder <Имя>` — один раз. Если сайт отвечает 410 (Tilda блокирует наш IP, П-014) — остановись, запиши «не проверено, блок 410», не перезапускай. Форму не отправляй.
2. **Образец:** ближайшая действующая кампания клиента (по Паспорту) — `gads_campaign_settings_xlsx.py --customer-id … --campaign-id … --client-folder …`; в данные пиши путь к xlsx и 5–8 строк сути (стратегия, бюджет, гео, языки, цели, число групп).
3. **Состояние объекта:** если задача про существующую кампанию — `gads_campaign_state_dump.py`.
4. **Объёмы и ставки по ключам** — `gads_keyword_volumes.py` (если в постановке есть список ключей или тема), показать диапазон ставки «верх страницы» и объём.
5. **Стоимость в операциях API** — `gads_clone_plan.py` / журнал `gads_quota_ledger.py`, сколько уже потрачено за сутки (лимит 15 000).

Не гоняй лишних запросов к кабинету: суточный лимит API (П-001); упёрся в лимит — остановись и сообщи.
