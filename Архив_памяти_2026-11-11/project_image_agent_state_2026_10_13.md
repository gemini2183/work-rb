Пользователь 2026-10-13 попросил агента/скилл/субагента для постоянного создания картинок, в связке с плейбуками агентов. Построено: плейбук `База_знаний/Агенты/Создатель_картинок.md`, субагент `.claude/agents/image-creator.md`, скрипт `Скрипты/image_tool.py` (specs/check/fit/generate), страница требований `База_знаний/Инструменты/Google-Ads-изображения-ассеты-требования-и-ИИ-метки.md`.

**Проверено:** `check` и `fit` на файлах ProfiMet. **Не запускалось:** `generate` — в окружении нет ключа Images API (`OPENAI_ADS_API_KEY` — от рекламного кабинета OpenAI Ads, картинки им не создать), и пользователь не выбрал сервис (OpenAI / Gemini).

**Why:** по умолчанию — реальные фото, не ИИ: ProfiMet 2026-10-08 отказался от картинок с ИИ-значком (на них люди-неклиенты), в ЕС/Индии/Нью-Йорке Google показывает видимую метку на ИИ-ассетах; Landver — без людей в кадре и учёт лицензий по Rule 7.2.

**How to apply:** на запрос про картинки — читать плейбук и вызывать `image_tool.py`, не предлагать генерацию как первый шаг; режим генерации только после «да» именно для этого клиента и картинки. Если пользователь дал ключ — сначала один тестовый `generate --execute` на безопасном фоне, потом обновить статус в плейбуке и в Инфраструктуре. Задачи с датой-невыставленной лежат в корневом `Задачи.md`. Связано: [[feedback_sessions_build_agent_playbooks]], [[feedback_no_facts_from_old_campaigns]].
