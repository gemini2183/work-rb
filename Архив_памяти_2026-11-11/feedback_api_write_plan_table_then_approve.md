Пользователь хочет, чтобы я писал в рекламные кабинеты напрямую через API (создание кампаний, правка объявлений и т.д.), но не вслепую: сначала показываю план в таблице (`Объект | Действие | Было → Станет | Откуда факт`; тексты — `Поле | Текст | Знаков/лимит | Откуда факт`), отдельным блоком — допущения, которые я выбрал сам. Пользователь согласует, говорит «да» — только тогда пишу. Договорённость 2026-10-06.

**Why:** при первой записи (`dspl_rtg_basket`) в живое объявление попал неактуальный состав подарков из старых кампаний — [[feedback-no-facts-from-old-campaigns]]. Таблица с источником факта ловит такое до записи. Пользователь прямо сказал, что формат можно подстраивать под удобство.

**How to apply:** новые кампании всегда на паузе, включение — отдельное согласование. До «да» максимум `validate_only`. После записи — прочитать обратно из аккаунта и показать фактическое состояние, залогировать в вики. Протокол закреплён в CLAUDE.md, раздел «Протокол записи в рекламные кабинеты».

**Состояние аккаунта — только свежим чтением.** 2026-10-07 я написал «кампания по-прежнему на паузе», не перечитав статус; пользователь за ночь включил её, снизил бюджет и сменил расписание. Любое утверждение про текущий статус/бюджет/расписание — только после запроса в том же ответе; иначе писать «на момент создания было X, сейчас не проверял».
