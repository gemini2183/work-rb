19.10.2026, LuxeBrokers /gold-silver: пользователь попросил проверить подмену на кнопке «Call now» и что вставить в Ringostat. Я полез в справку Ringostat и в код клиентского скрипта, хотя у нас есть `База_знаний/Инструменты/Ringostat-механизм-подмены-номера.md` (XPath-правила, маски, рецепты для Tilda) и `Скрипты/phone_swap_check.py`. Пользователь резко выразил недовольство: «мы делали подмены пятьсот тысяч раз».

**Why:** метод уже отработан и записан; повторное изобретение — трата времени и признак, что вики не читается. Пользователь ожидает, что система помнит.

**How to apply:** на любую операцию, которая уже делалась (подмена номера, сторожа, запись в кабинет, отчёты) — первым ходом `Grep` по `База_знаний/` и `Скрипты/README.md`, прочитать страницу, запустить штатный скрипт; ответ строить на нашем методе (для Ringostat: XPath + маска + ГЕО-группа All, проверка `phone_swap_check.py`). Правило закреплено в CLAUDE.md, раздел «Задача, для которой у нас уже есть метод». Связано: [[feedback-build-tools-for-recurring-work]], [[reference-ringostat-browser-management]].
