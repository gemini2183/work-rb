Правило пользователя (2026-10-13): в `shop_search` (customer 882-613-4558) оставить запросы с целевыми размерами 3x4/3x6/2x4/4x6, остальное минусовать; на уровне групп — только чужой целевой размер. Google не умеет «разрешить только», минусуются только уже появившиеся запросы.

**Состояние:** минусы живут в общих списках «Shop - запросы без размера 1/2» (EXACT, список 1 почти полон — писать в 2) и «размеры - есть в запросах, нет в фиде» (PHRASE), оба подключены только к `shop_search`. 13.10 записано +152 и +156. Отчёт по запросам видит ~31% кликов — потолок эффекта; видимого незакрытого было ~22 zł за 15 дней.

**Решение про автозапись:** система разрешений заблокировала режим самостоятельной записи в цикле. Пользователь выбрал полуавтомат: раз в 1–2 недели `gads_shopping_nontarget_negatives_plan.py` (чтение) → показать → «да» → `gads_shared_negatives_add.py`. Запросы с цифрами («3 на 6», «6mm») не минусовать — целевой спрос/толщина, на ручной разбор.

**Why:** автозапись в кабинет без подтверждения — то же ограничение, что у Планировщика Windows 08.10.
**How to apply:** по просьбе «минусы по shop_search» сразу запускать скрипт плана, не пересчитывать вручную; не предлагать Планировщик и автозапись повторно. Следующий прогон — 2026-10-27. Связано: [[feedback_build_tools_for_recurring_work]].
